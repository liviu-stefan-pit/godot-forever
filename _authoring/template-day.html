Concepts you need first

Physics bodies in one minute

A CharacterBody2D is a body you move from code (like a kinematic controller in other engines). You set velocity and call move_and_slide().

Coming from Unity/Unreal?

A Godot scene is both a prefab and a level; a node is a component and a game object in one.

Block 2: Build the player

Click "Mark done" on a step to track where you stopped.

  1. Create the project. In the Project Manager window, click Create (top-left). Set Project Name to g99-template, choose an empty folder, pick Forward+ (or Mobile for phone-only), then click Create.
  2. Add the root node. In the Scene dock (top-left), click Other Node, type CharacterBody2D, select it and click Create. Rename it Player by pressing F2.
  3. Add a collision shape. Select Player, press Ctrl+A, search CollisionShape2D, click Create. In the Inspector (right side), click the empty Shape field and choose New CapsuleShape2D.
  4. Save the scene. Press Ctrl+S, name it player.tscn, click Save. In the menu bar, Project > Project Settings > Input Map is where you will add actions later.

Check yourself

Which method must you call after setting velocity on a CharacterBody2D?

  • move_and_collide() only
  • move_and_slide()
  • translate()

In Godot 4 move_and_slide() takes no arguments and uses the body's own velocity.
