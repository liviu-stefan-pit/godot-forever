Part 1 · Day 7 · Game 2: Cave Runner

Platformer III: rooms, light, save

Cave Runner becomes a two-room game. The camera limits change with the room, the cave scrolls in layers, a lantern and a few occluders make the tiles read as a dark space, and a GameState autoload remembers coins, hearts, abilities and the last checkpoint in a JSON file. Esc pauses. The goal in room 2 ends the run.

Concepts you need first

The player outlives the room

On Day 5 the player node lives inside room_01.tscn. If you free that scene to load room 2, the player, the camera and the hearts go with it. Today the main scene is game.tscn. It owns the player, the HUD, the pause menu and the win screen. Rooms are children you swap. An autoload would be the wrong place for the player (it would outlive even the main menu in a later project); a parent scene is the right place. The autoload is only the small bag of facts that must survive the swap: coins, hearts, abilities, checkpoint.

Parallax2D

scroll_scale is a multiplier on camera motion. (1, 1) sticks to the world. (0.2, 0.2) crawls, so the layer reads as far away. repeat_size is the distance before the children wrap. The pictures are 1152x720, the same width as the viewport, so a repeat of (1152, 720) tiles them. Put the sprite's top-left on the origin (Centered off, position 0, 0). Do not use the older parallax nodes; Parallax2D replaces them.

2D lights need a dark base

A PointLight2D adds light on top of an already-lit canvas. Without a CanvasModulate, the cave stays fully bright and the lantern only washes it out. The modulate color is the ambient color in pixels no light reaches. LightOccluder2D holds an OccluderPolygon2D. Shadows show up only after the light's Shadow > Enabled is on, and only inside that light's texture.

JSON numbers are floats

JSON.stringify writes numbers. JSON.parse_string gives every one of them back as a float, even 3. Assigning that float to an int variable is a type error. Cast with int() on the way in. Vector2 is not a JSON type: store [x, y] and rebuild it. Bools and strings survive as themselves.

Block 3: Lantern, darkness, occluder

  1. Darken the canvas. Open game.tscn. Add a child CanvasModulate to Game (one is enough; a second would fight it). Set Color to hex 2E2942. This tints every canvas item on the default canvas. The HUD sits on its own CanvasLayer, so the hearts stay bright. Pixels a light never reaches stay this color.
  2. Add the lantern. Open player.tscn. Select Player, add a child PointLight2D, rename it Lantern. Drag assets/art/light.png onto Texture. Set Texture Scale to 2.2 (script name texture_scale). Color hex FFB56A. Energy 1.4. Blend Mode stays Add. Under CanvasItem, set Texture Filter to Linear so the gradient is smooth even though the project default is Nearest.
  3. Enable shadows on the lantern. Still on Lantern, unfold Shadow and tick Enabled (shadow_enabled). Set Filter to None (hard edges, cheapest, and the docs recommend it for pixel art). Leave Item Cull Mask at bit 1. Save the player scene.
  4. Occlude the big block. Open room_01.tscn. Select Room01, add a child LightOccluder2D, rename it BlockOccluder. Set Position to 640, 288 (top-left of the block painted on columns 20-27, rows 9-10). In the Inspector click Occluder > New OccluderPolygon2D. Click the new resource to expand it. Leave Closed on. Expand Polygon, set the array size to 4, and type the local points: (0, 0), (256, 0), (256, 64), (0, 64). The polygon is 8 tiles by 2 tiles, matching the block. Occluder Light Mask stays at bit 1, the same bit as the lantern's shadow cull mask.
  5. Occlude a stretch of floor. Duplicate BlockOccluder, rename the copy FloorOccluder, position 0, 576 (top of the floor, row 18). Edit its polygon (this duplicate shares the resource until you make it unique: click the Occluder dropdown > Make Unique, then edit). Four points: (0, 0), (1152, 0), (1152, 96), (0, 96). That covers the floor up to the pit and stops before columns 36-39, so the pit is not a solid shadow slab. Save.

You cannot F5 yet: game.gd does not exist, so the room is never instanced and apply_room_camera is not on the player. In the editor, with room_01.tscn open, BlockOccluder shows a rectangle over the big block and FloorOccluder shows a band on the left floor. If the polygon is a tiny dot at the origin, the points were typed on the node position instead of in the Polygon array, or Make Unique was skipped and both occluders share one rectangle.

Tiles can occlude too

A TileSet occlusion layer plus a polygon on each rock tile (same F shortcut as collision, under the atlas Rendering section) generates occluders for every cell. That is the right tool for a large cave. This day uses two LightOccluder2D nodes so you draw a polygon by hand once. The class reference and the tileset tutorial linked below cover the tile version.

Common pitfalls

  • Player or HeartsHud still inside room_01.tscn. You get two players or two heart rows, and freeing the room kills the one the camera is on. Both belong under Game.
  • Parallax sprite left centred. The repeat starts at (0, 0) and grows down-right. A centred 1152 px image covers x = -576 to 576, so half the loop is empty and the background pops.
  • CanvasModulate with no light, or a light with no CanvasModulate. The first is a flat dark cave. The second is a bright cave with a pale blob. You want both.
  • Shadow Enabled off. Occluder polygons do nothing visible until the light asks for shadows.
  • Shared OccluderPolygon2D after duplicate. Make Unique before editing the copy, or both nodes show the same rectangle.
  • Loading JSON straight into an int. coins = data["coins"] is a float. int(data.get("coins", 0)) is the counter.
  • Autoload Node Name typo. GameState is a global identifier. game_state does not match the scripts.
  • Pause menu left on Inherit. get_tree().paused = true then the button never receives the click, and Esc is not read either, so you cannot unpause.
  • Changing rooms inside body_entered without deferring. The area is freed mid-callback. request_room only emits; game.gd defers the actual load_room.
  • Forgetting monitoring off on the exit. The fade is short, but a second overlap can queue a second load. set_deferred("disabled"...) is for shapes; for the area itself set_deferred("monitoring", false) is the matching idea, and _busy is the second lock.

Check yourself

A parallax layer should feel far away. What do you set?

  • scroll_scale above 1
  • scroll_scale between 0 and 1, and a repeat_size that matches the art
  • ignore_camera_scroll on, scale 1
  • A second Camera2D on the sprite

scroll_scale multiplies camera motion. Smaller than 1 lags behind, which reads as distance. repeat_size is what makes the texture wrap instead of sliding off.

The lantern texture is assigned, Shadow Enabled is on, and the cave is still fully bright. What is missing?

  • A second Camera2D
  • Switching the renderer to Forward+
  • A CanvasModulate, because 2D lights only add on top of the current canvas color
  • Parallax2D.autoscroll

Without CanvasModulate the unshaded sprites are already at full brightness. The modulate color is what unlit pixels fall back to.

The save file contains "health": 2. After JSON.parse_string, what is that value's type, and what do you write?

  • A float; assign health = int(data.get("health", 0))
  • An int; assign it directly
  • A string; call JSON.parse_string a second time
  • A Vector2

JSON has a single number type. Godot's parser returns floats. Counters in this project are ints, so every loaded counter is cast. Bools and strings are left alone. Positions were stored as a two-element array because Vector2 is not a JSON type.

Esc sets get_tree().paused = true and the Resume button never fires. What do you change on the pause menu root?

  • Its CanvasLayer layer to 0
  • Turn monitoring off
  • Give it a CollisionShape2D
  • Process Mode = Always, so it still receives input while the tree is paused

Paused nodes on Inherit do not get _process, _physics_process or input. The menu has to opt out with Always. The Inspector path is Node > Process > Mode.

Why is the player a child of game.tscn instead of a child of each room?

  • CharacterBody2D cannot be instanced
  • Swapping the room frees that scene's children. The player, camera and HUD have to sit on the scene that stays
  • Autoloads are not allowed to store ints
  • Camera2D limits only work on the main scene root

The room is queue_free()'d on a transition. Anything parented to it dies. GameState keeps the numbers; the player node keeps the body, the camera and the state machine.
