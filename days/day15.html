Concepts you need first

One folder, five games

Publishable games in this course are not built from an empty project. You finish this template, then copy the whole folder and rename the copy. Idle clicker, bullet heaven, physics merge, deckbuilder, and deep digger all call the same autoloads. If a method name drifts, every later day breaks. The names below are the contract. Do not rename them, and do not add a required parameter.

Autoloads are process-wide singletons

An autoload is a node Godot creates before your main scene and keeps alive across change_scene_to_file. You reach it by the node name you type in Project Settings, the same way you reach AudioServer or Input. That is convenient and easy to overuse. This kit has five, and only five: a signal bus, settings, saves, a small audio facade, and a scene changer that fades. Game rules stay in res://game/, not in these scripts.

Coming from another engine?

An autoload is close to a Unity runtime singleton that is DontDestroyOnLoad, or an Unreal game-instance subsystem. The difference is the editor registers it. You do not new it yourself.

res:// versus user://

res:// is the project, packed into the export. user:// is per-user data outside the pack: settings, remapped controls, and saves. On Windows the game writes under %APPDATA%\Godot\app_userdata\<project name>\. The project name you set today is ship-kit, so that folder name follows the project name. Deleting res:// files does not delete saves. Deleting the app-userdata folder does.

What each autoload is for

AutoloadScriptJob
Eventsautoload/events.gdSignals only. Scenes do not grab each other to say "score changed".
Settingsautoload/settings.gduser://settings.cfg via ConfigFile. Volumes are linear 0.0–1.0. Also persists the Input Map.
SaveManagerautoload/save_manager.gdJSON slots in user://saves/, plus a small profile with a 1 second autosave. Flushes when the app pauses or closes.
Audioautoload/audio.gdPooled SFX players on bus SFX. Two music players crossfade on bus Music.
SceneRouterautoload/scene_router.gdCanvasLayer at layer 100. Fades, then change_scene_to_file.
JSON numbers

JSON.stringify writes numbers, and JSON.parse_string reads every one of them back as a float. A saved 12 comes back as 12.0. Any counter you treat as an int must be cast with int(...) at the load site. Idle-clicker values that can exceed 2^53 must be stored as strings, not ints. The slot envelope itself casts its format field. Your game dictionary is returned as parsed.

Buses: Master, Music, SFX

Every exported game loads res://default_bus_layout.tres at startup. Settings looks up buses by name. A typo here means volume sliders silently fail tomorrow.

  1. Open the Audio panel. Along the bottom panel, click the Audio tab. You should see one bus column named Master. Master is the speakers. Do not rename it and do not delete it.
  2. Add Music. Click the Add Bus button (the plus at the right of the bus row). A column appears. Double-click its name and type Music, then press Enter. Under that name, the output dropdown must say Master. If it says something else, open it and choose Master.
  3. Add SFX. Click Add Bus again. Rename the new column to SFX in all capitals. Set its output to Master the same way. You now have three columns, left to right: Master, Music, SFX.
  4. Save the layout. Click anywhere on the 2D viewport, then press Ctrl+S if Godot asks about unsaved changes. In FileSystem, res://default_bus_layout.tres exists. Godot rewrites that file when you edit buses. If you do not see it, click the FileSystem refresh, or switch away from the Audio tab and back.
Names are case-sensitive

The scripts use &"Music" and &"SFX". Sfx, sfx, and Sound are different buses. AudioServer.get_bus_index returns -1 for a missing name, and Settings pushes an error instead of guessing.

The Audio tab shows exactly three buses: Master, Music, SFX. Music and SFX both send to Master. default_bus_layout.tres is in FileSystem.

Autoload 1 and 2: Events and Settings

Create each script from the FileSystem, then register it. The node name in the Autoload list is what you type in GDScript. Godot's suggested name is often the filename in lowercase. You must replace it.

  1. Create events.gd. In FileSystem, right-click res://autoload and choose Create New > Script.... Language GDScript. Inherits Node. Path res://autoload/events.gd. Template Empty. Click Create. The script editor opens. Press Ctrl+A, delete everything, and paste this whole file.
  2. Register Events. Menu bar: Project > Project Settings. At the top of that dialog, click the Globals tab. Autoload is the section on the left (not Global Groups). At the bottom, click the folder icon beside Path. Choose res://autoload/events.gd and confirm. The Node Name field will say events. Change it to Events with a capital E. Leave the enable checkbox on. Click Add. A row appears: name Events, path res://autoload/events.gd. The singleton checkbox on that row stays on, so scripts can write Events without get_node.
  3. Create settings.gd. Same FileSystem flow: right-click res://autoload > Create New > Script..., inherits Node, path res://autoload/settings.gd, template Empty. Replace the whole file.
  4. Register Settings. Back on Project > Project Settings > Globals > Autoload. Path: res://autoload/settings.gd. Node Name: Settings (capital S). Click Add. It must be the second row, under Events.
Why linear volume

Sliders in this kit store 0.0–1.0. AudioServer.set_bus_volume_linear turns that into decibels. Do not pass a decibel value into set_volume. Audio.play_sfx is the method that takes volume_db, and that is a per-sound offset on top of the bus.

Autoload 3: SaveManager

  1. Create save_manager.gd. Right-click res://autoload > Create New > Script..., inherits Node, path res://autoload/save_manager.gd. Replace the whole file.
  2. Register SaveManager. Project > Project Settings > Globals > Autoload. Path res://autoload/save_manager.gd. Node Name SaveManager (capital S, capital M, one word). Click Add. It is the third row.
Why flush on pause

Android can kill a paused app without a close notification. NOTIFICATION_APPLICATION_PAUSED and NOTIFICATION_APPLICATION_FOCUS_OUT are the last reliable moments to write. quit_game on SceneRouter also calls SaveManager.flush() before get_tree().quit(). Desktop close is handled here too, because this script turns off auto-accept quit and quits only after the file write returns.

Autoloads 4 and 5: Audio and SceneRouter

  1. Create audio.gd. New script on res://autoload, inherits Node, path res://autoload/audio.gd. Replace the whole file.
  2. Register Audio. Autoload path res://autoload/audio.gd, Node Name Audio. Click Add. Fourth row.
  3. Create scene_router.gd. New script, and this time set Inherits to CanvasLayer (search that name in the Inherits field). Path res://autoload/scene_router.gd. Then replace the whole file anyway, so the extends line is the one below.
  4. Register SceneRouter. Path res://autoload/scene_router.gd. Node Name SceneRouter (capital S, capital R). Click Add. It is the fifth and last row.
  5. Check order and singletons. The Autoload list must read, top to bottom: Events, Settings, SaveManager, Audio, SceneRouter. Each row's enable box and singleton box are on. If a row is in the wrong place, select it and use the up or down arrow on the right of the list until the order matches. Click Close.

Reopen Project > Project Settings > Globals > Autoload. Five rows, those exact names, those exact paths. The Output panel has no red parse errors. If the debugger says Identifier "Events" not declared, the node name is not Events or the singleton box is off.

Color is a value

Color is copied when you read it. _fade.color.a = 1.0 changes the copy and leaves the rect alone. The script writes a whole Color back in _set_fade_alpha. The tween path color:a is fine: tween_property sets that component itself.

Common pitfalls

  • Node Name left as events. GDScript then has no global Events. The Autoload row name is the API. Capitalization is part of the name.
  • Singleton checkbox off. The node still exists in the tree, but other scripts cannot say SaveManager.flush(). Turn the checkbox back on.
  • Wrong order. Settings._ready does not call the other kit scripts, but later UI will. Keep Events first so any emit during startup has a bus. Keep SceneRouter last.
  • scene_router.gd extends Node. layer belongs to CanvasLayer. The file in this lesson starts with extends CanvasLayer. A parse error on layer means the extends line was not replaced.
  • Bus renamed after a player pointed at it. Stream players remember the bus name. Renaming SFX sends those players back to Master. Fix the name; do not hunt for a hidden volume.
  • Treating a loaded score as an int without int(). loaded["boot"] == 1 can fail a typed int check because the value is float. The smoke test casts. Do the same in every game.
  • Saving into res://. Exports are read-only. Only user:// is writable on a player's machine. The kit paths are already user://. Do not "simplify" them.

Challenge (optional, 20-30 min)

Toggle fullscreen from the smoke test

In game.gd, add an _unhandled_input that calls Settings.set_fullscreen with the opposite of Settings.is_fullscreen() when a key you choose is pressed. Run with F5, press the key, and confirm two things: the window fills the monitor, and user://settings.cfg contains fullscreen=true under [video]. Press the key again and the window returns.

Hint: Settings.set_fullscreen already writes the config and emits Events.settings_changed. You do not add a second save call. Stop the game before you look at the cfg file, or the next boot will apply fullscreen immediately. That is the point of _apply_fullscreen.

Check yourself

What is the autoload order in Project Settings?

  • Audio, Events, Settings, SaveManager, SceneRouter
  • SaveManager, Settings, Events, Audio, SceneRouter
  • Events, Settings, SaveManager, Audio, SceneRouter
  • SceneRouter, Events, Audio, Settings, SaveManager

That order is the contract. The node names use that capitalization, not the filenames.

What does Settings.get_volume(&"Music") return?

  • A linear loudness from 0.0 to 1.0
  • Decibels, usually between -80 and 0
  • The bus index
  • An AudioStreamPlayer

The slider value and the config file stay linear. AudioServer.set_bus_volume_linear converts to dB. play_sfx's volume_db argument is a separate per-sound offset.

A slot file written by SaveManager.save_slot contains which top-level keys?

  • version, payload
  • format, saved_at, data
  • slot, json
  • The dictionary you passed, with no envelope

format is FORMAT_VERSION (1). saved_at is a unix time. data is your dictionary. On load, cast integers inside data yourself.

How does SceneRouter.go_to change the running scene?

  • It frees the current scene with queue_free and instances a hard-coded path
  • It calls get_tree().reload_current_scene only
  • It changes SceneTree.current_scene by assigning a string
  • It fades, calls change_scene_to_file, waits for scene_changed, then fades in

The fade is a ColorRect on a CanvasLayer at layer 100. The scene call is change_scene_to_file, which is deferred, so the script awaits scene_changed before fading back in.

Which bus does Audio.play_sfx send players to?

  • Master
  • Music
  • SFX
  • Whichever bus was selected on the last AudioStreamPlayer you placed in the editor

The pool sets bus to SFX. Music uses two players on Music. Both of those buses send to Master, so the Master slider still affects them.
