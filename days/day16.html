Concepts you need first

The base size is not the phone size

1280×720 is the size you design at. Stretch mode canvas_items draws 2D at the real window size, scaled from that base. Aspect expand keeps the ratio and gives extra pixels on the long side instead of adding black bars. Anchors and containers spend those extra pixels. Portrait games later set the base to 720×1280. They do not change the autoloads.

Focus is a separate input path

Buttons already listen to the built-in actions ui_up, ui_down, ui_left, ui_right, and ui_accept. A gamepad works on menus only after some control has focus. grab_focus() does that. Do not bind gameplay code to ui_accept. Gameplay uses confirm, cancel, and pause.

Release is not the editor

The editor play button is a debug run. A store build is an export preset plus the matching export templates. Export With Debug left on produces a build Play and Steam both treat as a debug package. You will uncheck it every time you export a file you might upload.

Version note

Godot 4.7 and later create new projects with stretch mode canvas_items already. Older 4.x defaults that mode to disabled. Either way, set the two fields in the next section yourself. Godot 4.8 can install the Android SDK from the editor. If your editor has that button, use it, and skip the manual JDK path only if the editor says the SDK is ready.

Why ui_accept stays

Focus uses ui_accept, which already includes the pad's south button and Enter. confirm is for gameplay. Sharing a physical button across two actions is normal. Do not delete the ui_* rows to "clean up".

What remap keeps

A new keyboard event replaces other keyboard events on that action and leaves joypad events in place. A joypad button replaces other joypad buttons. The click that opened the row is ignored, because mouse buttons are not stored. Settings.save_input_map writes user://input_map.cfg. The next boot calls load_input_map from Settings._ready.

Touch on a desktop mouse

Input.action_press updates Input.get_vector. It does not send a fake event through _unhandled_input. That is why the touch buttons call action_press and the pause button calls toggle() directly. On a phone, emulate_mouse_from_touch is already on by default, so a finger activates Button nodes. You do not need Emulate Touch From Mouse for this test.

Signed Android App Bundle

  1. JDK 17 and the Android SDK. Follow Exporting for Android for this editor's version. You want OpenJDK 17. The docs recommend 17 even if a newer JDK can work. Then the Android SDK. Godot 4.8 and later can download both from the editor (the same page describes that dialog). On an older 4.x editor, use that page's manual section and ignore commands that your editor's page does not list. The master branch of the docs moves. Use the version selector on the docs site so the page matches your editor.
  2. Tell the editor the two paths. Editor > Editor Settings. Search android. Set Java SDK Path to the JDK 17 folder (the folder that contains bin\java.exe). Set Android SDK Path to the SDK folder that contains platform-tools\adb.exe. On a typical Windows Android Studio install that is %LOCALAPPDATA%\Android\Sdk. Close Editor Settings.
  3. Install the Gradle build files. Menu bar Project > Setup Android Build.... Confirm. Godot writes res://android/build. If your editor's Project menu instead says Install Android Build Template, that is the same step on older 4.x. Either item is the one that creates res://android/build. You need export templates installed first or the menu will offer to download them.
  4. Add the Android preset. Project > Export... > Add... > Android. In the options on the right, open Gradle Build and enable Use Gradle Build. Set Export Format to the Android App Bundle option. The label includes aab. Leave apk and aar alone. An App Bundle is what Play has required for new apps since August 2021.
  5. Package name. In the preset options, find Package > Unique Name. Set it to com.yourname.shipkit, with your own name in lowercase letters, replacing yourname. Only a-z, digits, underscores, and dots. Each segment must start with a letter. When you copy this project for a real game, you change this string and you never reuse it. Play rejects a name another app already published.
  6. Screen insets. In the same options, open Screen. Enable Edge To Edge. Leave Immersive Mode off. Edge-to-edge is why safe_area.gd exists: the status bar draws over your content, and the safe rect tells you the padding. If this checkbox is missing on an older editor, skip it. On desktop, a window that sits inside the work area keeps those margins at zero, because the script converts the screen rectangle into window coordinates first.
  7. Create the keystore. In File Explorer, create C:\GodotProjects\keystores. Open PowerShell. The docs' command is keytool -v -genkey -keystore ... -alias ... -keyalg RSA -validity 10000. Use it with this path and alias: If PowerShell does not find keytool, run the keytool.exe inside the JDK's bin folder with the same arguments. Answer the name prompts with anything you will remember. When it asks for a keystore password and then a key password, type the same password both times. Godot's Android exporter currently requires those two passwords to be equal. Use letters and digits. The docs warn that special characters can fail. Do not put -storepass on the command line. It stays in shell history. Do not commit the keystore or the password.
  8. Point the preset at the keystore. Back in the Android export options, fill the release fields the Android export docs list: Release = C:\GodotProjects\keystores\ship-kit.keystore, Release User = shipkit, Release Password = the password you typed twice. There is a separate debug keystore block. Leave debug alone. You are not shipping that key.
  9. Export the AAB. Set the preset export path to C:\GodotProjects\ship-kit-build\android\ship-kit.aab (create the folder). Click Export Project.... Uncheck Export With Debug. Save. The first Gradle build downloads dependencies and can take several minutes. A red Gradle error usually means the JDK path, the SDK path, or a password mismatch.

ship-kit.aab exists and is larger than a few megabytes. The export log does not say the package is unsigned. Export With Debug was off. If you have a phone, Day 30 is when you install from a Play track. Installing an AAB directly needs bundletool. You do not need that today. If the build says the keystore password and the key password differ, recreate the keystore and type one password for both prompts.

Keep the keystore

Common pitfalls

  • Button text set to Play instead of UI_PLAY. Auto-translate looks up the Text property as a key. English words that are not keys never change language.
  • CSV saved as UTF-16 or with a BOM. The importer drops characters or refuses the header. Re-save as UTF-8 without a BOM. The docs suggest LibreOffice when Excel or Notepad fights you.
  • Translations imported but not added under Project Settings, Localization. The keys stay on the buttons.
  • Pause menu left on the default process mode. Escape seems dead, or the dim appears and no button works, because the paused tree stopped the menu. Mode must be Always. The pause button on the game scene also needs Always if you want to tap it while paused. Resume lives on the menu, so it is the reliable close path.
  • Main scene still game.tscn. F5 skips the menu. Application > Run > Main Scene is res://ui/main_menu.tscn.
  • Export With Debug checked. The file runs, and Play later rejects it or treats it as debuggable. Uncheck it on every store export.
  • Keystore password different from the key password. keytool allows that. Godot's Android preset does not. Recreate the file with one password.
  • Package name com.yourname.shipkit reused for two Play apps. The second upload is a different game and cannot share the name. Change Unique Name when you copy the template.
  • Calling Settings.set_volume from a slider that also applies settings_changed by writing the slider. value_changed fires when code sets value. This menu sets the slider before connecting. Keep that order if you edit the script.

Challenge (optional, 20-30 min)

Return from settings to the open pause menu

Today, Settings from the pause menu stores return_scene and loads game.tscn again. The square resets because the scene is new. Save the token position with SaveManager.set_value in ShipPauseMenu._on_settings_pressed, and read it back in game.gd _ready. Hint: the value passes through JSON, so a Vector2 will not round-trip. Store {"x": token.position.x, "y": token.position.y} and cast with float() on load. Do not add a new autoload method. set_value / get_value on SaveManager are the profile API, and they autosave a second later. Call flush() before go_to so a crash on the next scene cannot drop the point.

Check yourself

Which stretch pair does this template use?

  • Mode viewport, aspect keep
  • Mode canvas_items, aspect expand
  • Mode disabled, aspect ignore
  • Mode canvas_items, aspect keep_width

Publishable games in this course use canvas_items and expand so a taller or wider phone adds space instead of bars. The base size stays 1280×720 until a game copies the project and changes it.

What must the first row of translations.csv start with?

  • keys, then locale codes such as en, es, de
  • id,english,spanish
  • The English sentence in column A, with no header
  • msgid,msgstr

Godot's CSV importer treats column 1 as the key and the other headers as locale codes. This kit fills en, es, de, fr, pt_BR, ru, and zh_CN. UI keys start with UI_.

Why is the pause menu's process mode Always?

  • So the menu runs on a thread
  • So CanvasLayer draws above the fade
  • Always is the default for every Control
  • A paused tree does not process pausable nodes, and the menu must still take input

get_tree().paused = true stops the game square and ordinary buttons. The menu sets PROCESS_MODE_ALWAYS and emits Events.game_paused.

Which statement matches the Android export docs?

  • A debug APK is enough for new Play apps
  • The keystore password must differ from the key password
  • Ship an AAB from a Gradle build, sign with a non-debug keystore, and uncheck Export With Debug. The keystore password and the key password have to match.
  • JDK 8 is the version the current Android export page asks you to install

The Android export page says new Play apps need an AAB, which needs the Gradle build, a non-debug keystore, matching passwords, and Export With Debug unchecked. It tells you to install OpenJDK 17.

Where does a remapped key survive a restart?

  • project.godot is rewritten by the running game
  • user://input_map.cfg, loaded by Settings.load_input_map
  • user://saves/run.json
  • It cannot survive; Input Map is editor-only

save_input_map stores var_to_str of each event. load_input_map runs from Settings._ready. The editor Input Map remains the default for a fresh user folder.
