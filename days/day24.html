Concepts you need first

Data on disk, a fight in memory

A card design is a Resource saved as .tres. That is the same idea as a ScriptableObject or a data-only prefab: one Strike asset, many references. A fight does not edit that asset. It creates a small CardInstance (a RefCounted, not saved) each time a card enters the combat deck. Anger can spawn another instance that dies when the fight ends, and the authored Strike file stays a single card.

Custom resources show up in the Create Resource dialog only after the script has class_name and compiles. That is why the scripts come before the .tres files.

Four piles and a phase

The combat deck is the draw pile. You draw 5, spend energy (3 at the start of your turn, unspent energy is discarded), then End Turn moves the hand onto the discard pile. An empty draw pile shuffles the discard pile back in. Exhaust is a third pile: the card is gone until the next fight, and the run's real deck (a list of ids) is untouched. Powers exhaust. True Grit also exhausts a random other card still in hand.

The phase is an enum: PLAYER, then ENEMY, then either the next player turn or VICTORY / DEFEAT. Buttons and, tomorrow, drop targets ask the phase before they accept a card.

Damage, Block, and the two debuffs

Block absorbs damage, then leftover damage hits HP. Block on a fighter is cleared at the start of that fighter's turn. Strength is a flat bonus added before multipliers. It does not tick down.

For one hit, in this order: add the attacker's Strength; if the attacker has Weak, multiply by 0.75 and floor; if the target has Vulnerable, multiply by 1.5 and floor. Weak and Vulnerable then count down by 1 at the end of the afflicted fighter's turn. A card applies its debuff after its own damage, so Bash does not boost the same hit that applied Vulnerable. Later cards in that hand do.

Consequence you should expect in the log: an enemy who applies Vulnerable 1 would watch it tick off at the end of your turn, before that enemy swings again, so the debuff would miss. Enemy Vulnerable on this page is therefore 2, which is still 1 when the next hit lands. Weak 2 on you weakens two of your turns, because Weak matters on your turn, before the tick.

Save shape, used on Day 26

to_dictionary() stores ids and ints only. SaveManager.save_slot writes JSON, and JSON turns every number into a float. from_dictionary() puts each loaded number through int(). Do not remove those casts when you wire the slot. Pile shuffle uses Array.shuffle() (global RNG). Reward offers on Day 26 use a separate RandomNumberGenerator so a saved shop does not reroll.

Common pitfalls

  • CardData missing in Create Resource. The script has a parse error, or it was saved after you opened the dialog. Check Output, then Project > Reload Current Project.
  • Empty pattern slots. An [empty] IntentStep crashes when that turn arrives. Every array slot needs New IntentStep.
  • Five Strike files. The starter deck wants the id strike five times. Extra .tres files with the same id overwrite each other in the catalog dictionary.
  • Lambdas in the hand loop. bind(card.uid) stores the uid at connect time. A lambda that reads the loop variable reads whatever card is last.
  • Rebuilding the hand inside the button signal. _rebuild_hand is deferred so the button that was clicked is not freed inside its own pressed callback.
  • Main scene swapped. F5 should open the menu. If it opens the fight directly, set Main Scene back to res://ui/main_menu.tscn.
  • Block "does nothing". Block is cleared at the start of your next turn. It only matters during the enemy phase that follows End Turn. Anchor (Day 26) is applied after that clear, and only on turn 1.
  • JSON later. If a resumed fight has 11.0 energy or a bad phase, an int() cast was skipped in from_dictionary.

Check yourself

Why is Strike a Resource and the card in your hand a CardInstance?

  • Resources cannot store integers, so the hand needs a second type.
  • The .tres file is the shared design. The fight holds lightweight instances so a copy added by Anger disappears when the fight ends.
  • Godot only allows one Resource in memory at a time.
  • class_name works only on RefCounted.

Editing the Strike resource would edit every future Strike. Instances point at that resource and live in the piles for one fight.

The draw pile is empty and the discard pile has cards. You draw one. What happens first?

  • The draw fails and the hand stays short forever.
  • The top of the exhaust pile is drawn.
  • The discard pile is moved onto the draw pile and shuffled, then one card is drawn.
  • The run deck is copied again from disk.

_draw shuffles the discard into the draw pile only when the draw pile is empty and the discard pile is not. Exhaust stays out.

You have 5 Block and the Jaw Worm's intent is Attack 11. You press End Turn without playing a Defend. What hits your HP?

  • 6. Block absorbs 5, then your Block is cleared at the start of the next player turn.
  • 11. Block is cleared at the end of the player turn, before the enemy acts.
  • 0. Block always lasts the whole fight.
  • 11, and Block stays at 5.

End Turn does not clear Block. The enemy hits, Block absorbs, then the next _begin_player_turn sets Block to 0 before you draw.

Bash deals 8 and applies 2 Vulnerable. The enemy has no Vulnerable yet. How much HP does that Bash hit remove, before Block?

  • 12, because Vulnerable applies first and 8 × 1.5 = 12.
  • 8. The debuff is applied after this card's damage. A later card in the same hand sees Vulnerable.
  • 6, because every attack is multiplied by 0.75.
  • 10, because Bash also grants 2 Strength.

_resolve deals damage, then adds Weak or Vulnerable. Floor of 8 × 1.5 would be the next damaging card, not Bash itself.

Day 26 will save energy with SaveManager.save_slot. The fight loads and energy is the float 2.0. What does from_dictionary do?

  • It refuses the file, because JSON cannot store numbers.
  • It assigns the float straight into the int variable and hopes the warning is harmless.
  • It stores energy as a Vector2 so JSON keeps the type.
  • It wraps the loaded value in int(), because JSON numbers come back as floats.

The slot format is JSON. Every number becomes a float on load. Counters, HP, energy, turn, and intent index are cast with int().
