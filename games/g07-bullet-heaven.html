Bullet Heaven

A landscape survivor. You move, weapons fire on their own, and the swarm is a list of canvas items rather than a list of nodes. Gems raise a level, a level is a paused choice of three Resources, and a coin shop between runs unlocks two more characters. The menus, settings, pause, and save flush come from the Ship Kit.

Days 19–21CharacterBody2D, Camera2D, RenderingServer, Resources1280×720 · canvas_items · expand · Mobile

Game design

One run is a clock. Bats (and, after two minutes, brutes) walk straight at the player. Standing in them drains HP per second. Weapons never need an aim button. Gems grant XP. At each level the tree pauses and you pick one card: a new weapon, a weapon rank, a new passive, a passive rank, an evolution, or a 25 HP heal if the pool is empty. At 8:00 the Warden spawns once. Dying writes coins and bests, then offers retry or the main menu.

Controls. Keyboard and gamepad use move_left, move_right, move_up, move_down. Touch uses a VirtualJoystick (or the fallback Control if that node is missing) that presses those same actions. pause is the Ship Kit pause menu. There is no attack button.

Project. Copy C:\GodotProjects\ship-kit to C:\GodotProjects\bullet-heaven. Viewport 1280×720, stretch mode canvas_items, aspect expand, renderer Mobile. Android package com.yourname.bulletheaven (replace yourname). Canvas-item RIDs draw on Forward+, Mobile, and Compatibility; Mobile is the phone default, not a requirement of the swarm.

Formulas

Level starts at 1. xp_to_next(level) = round(12 × 1.22^(level − 1)). Bat gem = 1 XP, brute = 3, Warden = 8 gems of 5. Minute = int(seconds / 60).

  • Bat: HP round(14 × (1 + 0.18 × minute)), speed min(160, 78 + 3 × minute), contact 8 + minute HP/s, radius 11.
  • Brute (minute ≥ 2, 22% of spawns): base HP 36 on the same curve, speed min(110, 56 + 2 × minute), contact 14 + 2 × minute, radius 18.
  • Spawn interval max(0.04, 0.55 × 0.90^(seconds / 30)). Alive cap 1100. Gems pool at 160; a full pool grants XP with no icon.
  • Weapon damage (base + per_level × (L − 1)) × (1 + 0.08 × might_ranks + 0.04 × shop_might) × evo. Evo multipliers: Needle 1.25, Orbit 1.40, Scatter 1.15.
  • Cooldown max(min, base + per_level × (L − 1)) × max(0.45, 1 − 0.06 × tome_ranks) × evo. Evo cooldown: Needle 0.55, Orbit 0.62, Scatter 0.70.
  • Projectile count base + floor((L − 1) / every), every = 2. Evolved Needle and Orbit add 2. Evolved Scatter becomes at least 8. Orbit hits each enemy at most once per tick.
  • Move speed 210 × (1 + 0.08 × stride_ranks) × character_speed. Magnet 72 + 28 × magnet_ranks + 20 × shop_magnet_rank. Armor subtracts 2 × armor_ranks from contact HP/s, floored at 0.
  • Evolution: weapon level 8 and the named passive at rank 5. Needle + Quick Hands, Orbit + Iron Will, Scatter + Long Arms. The evolution replaces that weapon.
  • Warden at 480 s: 8000 HP, 48 px/s, 22 contact HP/s, radius 36, ring of up to 12 shots every 2.4 s at 160 px/s for 14 HP each. Death adds 50 kills.
  • Coins floor((kills × 0.25 + seconds × 0.5 + boss_kills × 200) × (1 + 0.08 × purse_rank)). Next shop rank costs base × 2^rank (rank 0..4). Vitality +15 HP, Sharpened +4% damage, pocket magnet +20 px, purse +8% coins. Max HP = 100 + character_hp + 15 × vitality_rank.

Scope: what "done" means

Store-ready here means the run is the one in the tables, the Ship Kit shell is still the shell, and both export targets boot. Stretch goals are not required to tick this list.

  • Main menu, settings (volume, fullscreen, locale), pause, and credits are the Ship Kit scenes, not a second menu kit.
  • Start reaches res://game/game.tscn through SceneRouter. Retry calls reload_current. Menu calls go_to(MAIN_MENU_SCENE).
  • Player, camera, three weapons, six passives, evolutions, gems, and the level-up pause all match the formulas above.
  • Virtual joystick or the documented fallback drives move_*. Keyboard still works.
  • BH_ keys exist in en, es, and de (the CSV header still has the Ship Kit columns) and the cards use tr().
  • Horde is canvas items. With Stress Spawn on, BH/Alive can pass 1000 while Object Count stays within about 30 of the count printed at launch. Stress Spawn is off in the exported scene.
  • Warden, three characters, and the four shop tracks use the prices and effects in the tables. Coins and ranks are read back with int() and flushed on death.
  • Save keys: bh_coins, bh_best_kills, bh_best_time, bh_unlocks, bh_might_rank, bh_hp_rank, bh_magnet_rank, bh_purse_rank.
  • Windows exe under build\BulletHeaven.exe boots the menu and keeps coins. Android debug package id com.yourname.bulletheaven installs and the stick works. Release keystore and Play listing are later days.
  • Credits and licenses/THIRD_PARTY.txt mention Kenney only if those files are actually in the export. Godot's license files from the Ship Kit are still present. Icon and version are set (0.1.0).

Architecture

Game (Node)                         [game.gd, class RunDirector]
├── World (Node2D)
│   ├── Player                      [player.gd] Camera2D child, group "player"
│   ├── Horde (Node2D)              [horde.gd] 1200 canvas-item RIDs, position (0, 0)
│   ├── Projectiles                 40 pooled Projectile nodes
│   ├── Gems                        160 pooled Gem nodes
│   ├── Loadout (Node2D)            [loadout.gd] weapons, passives, orb sprites
│   └── Boss                        [boss.gd] Warden + 24 ring sprites
├── HUD (CanvasLayer 10)            [hud.gd]
├── LevelUp (CanvasLayer 30)        [level_up.gd] process mode Always
├── Front (CanvasLayer 40)          [front.gd] select + shop, process mode Always
└── PauseMenu                       instance of ui/pause_menu.tscn

Loadout never names RunDirector. It calls player_position, nearest_enemy, enemy_position, enemies_near, borrow_shot, and damage_enemy. Horde ids are 0..1199. The Warden is id 1000001. The cell hash (64 px, buckets reused) only stores horde ids; the boss is tested by distance beside that result. Autoload order stays Events, Settings, SaveManager, Audio, SceneRouter.
