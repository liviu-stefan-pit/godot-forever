Physics Merge: Fruit Jar

A Suika-style jar. Drop a fruit, two of the same tier become the next tier exactly once, and a fruit that sits above the line loses. The course calls it Physics Merge. The phone shows Fruit Jar.

Days 22–23RigidBody2D · seeded RNG · MERGE_

Game design

Portrait playfield, 720×1280. The player aims a ghost along y = 150 and drops it. Mouse press drops; a finger drops on release so the drag can aim. The next tier (0–4 only) shows as a small circle. Two touching fruits of the same tier become one fruit of the next tier. Planet (tier 10) does not merge. The run ends when any settled fruit keeps its center above y = 250 for 2 seconds. Retry and Menu use SceneRouter.

Modes. Endless calls randomize(). Daily sets RandomNumberGenerator.seed to int(unix_time / 86400) (UTC day). The queue matches across restarts. The physics stack does not, so the daily best is local to this install.

Playfield and body

Inner walls at x = 48 and x = 672 (gap 624). Floor surface y = 1168 (rectangle center (360, 1208), size (624, 80)). Side walls are 48 px thick, centered at x = 24 and x = 696. Project gravity 1600, vector (0, 1), solver iterations 16. Each fruit: gravity scale 1, linear damp 0.8 and angular damp 2.0 in Replace mode, lock rotation off, CCD cast-shape, contact monitor on, max contacts 6, layer pickups (layer 6, value 32), mask world+pickups (value 33). Shared material: friction 0.40, bounce 0.12, absorbent off. Walls: layer world, mask pickups.

Drop grace 0.75 s. Merge-spawn grace 0.4 s. Drop lock 0.35 s. Combo window 1.5 s. Combo starts at 1 and adds 1 per extra merge inside the window. Score added is (tier * tier * 2) * combo for the tier that appears.

Radius table is round(18 * 1.22 ^ tier) stored as integers, not recomputed. Mass is 0.35 * 1.25 ^ tier rounded to two decimals and stored. Pitch is 1 + 0.07 * tier. Camera shake is 0.18 s, ±8 px, only when the new tier is 7 or higher, and it uses randf_range, not the drop RNG.

The lower get_instance_id() emits the merge. Both bodies set merging immediately. Layers clear with set_deferred. The child fruit is call_deferred. Each fruit gets CircleShape2D.new() so radii are not one shared subresource.

Assets and credits

No sprite pack. Fruits are Polygon2D circles from FruitTable.circle. The pop sound is synthesized. Optional: a food pack from kenney.nl/assets (CC0). Pick round images by eye; filenames differ between versions. Credit line if you add them: "Fruit sprites: Kenney (www.kenney.nl), CC0". Godot license files stay in res://licenses/ from the kit.
