Deckbuilder

A landscape run of fights, shops, and relics. You spend energy to play a small deck, read enemy intents, and climb a branching map. Quit mid-fight and Continue puts the same hand back. The project is C:\GodotProjects\deckbuilder, copied from the Ship Kit, package com.yourname.deckbuilder.

Days 24–26CardData, Control drag-and-drop, SaveManager

Game design

One run is one map. You start at 70 HP and 99 gold with Strike ×5, Defend ×4, and Bash ×1. Each room is a button. Only rooms connected to the one you just cleared are enabled. A combat spends 3 energy a turn and draws 5 cards. Block clears at the start of that fighter's turn. Weak multiplies outgoing damage by 0.75, Vulnerable multiplies incoming damage by 1.5, both floored, and both tick down at the end of the afflicted fighter's turn. Strength is a flat bonus and does not tick down.

Mouse or touch: drag a card onto your panel (skills and powers) or onto an enemy (attacks, including Cleave, which hits every living enemy). End Turn is a button. Pause is the Ship Kit pause action. There is no movement input.

You win the run by beating the Ash Titan (86 HP) and taking or skipping the boss card reward. You lose when HP hits 0. The run slot is deleted either way. Best floor (1-based row of the room you were in) stays in the profile.

Damage for one hit is base + attacker Strength, then ×0.75 if the attacker has Weak, then ×1.5 if the target has Vulnerable, each product floored. Block absorbs before HP. Bloodletting's 3 HP loss ignores Block. Bash applies Vulnerable after its own hit.

Scope: what "done" means

Store-ready means the Ship Kit shell plus a run you can leave and resume, in English, Spanish, and German, exported for Windows and Android. Stretch goals stay off this list.

  • Main menu Play opens the map. Continue resumes user://saves/run.json, including a fight in progress.
  • Play while a slot exists asks before replacing it.
  • Drag-and-drop combat: energy, draw, discard, exhaust, intents, the twelve cards, two enemies when the room says so.
  • Rewards, shop, rest, treasure, five relics, Ash Titan.
  • Best floor stored with SaveManager.set_value("deck_best_floor", n) and flush(). Loaded values that JSON turned into floats are cast with int().
  • Settings still change Master, Music, and SFX, fullscreen, and locale. DECK_ keys resolve in en, es, and de.
  • Pause and credits work. licenses/THIRD_PARTY.txt states that cards and enemies are Godot ColorRect and Label nodes.
  • 1280×720, stretch mode canvas_items, aspect expand, Mobile renderer, handheld orientation landscape.
  • Android unique name com.yourname.deckbuilder. Windows release export and an Android debug install, using the Day 16 export steps.

Architecture

Autoloads stay the Ship Kit five, in this order: Events, Settings, SaveManager, Audio, SceneRouter. SceneRouter.GAME_SCENE is res://game/game.tscn. The main scene stays res://ui/main_menu.tscn. No new autoload.

Game (Control)                    [game.gd]
├── %MapScreen                    [map_screen.gd]
├── %Combat                       [combat.gd]
│   └── hand, enemy row, drop panel
├── %RewardScreen
├── %ShopScreen
├── %RestScreen
├── %ResultScreen
├── %Confirm (Panel)
└── PauseMenu                     (Ship Kit scene)

Battle is a RefCounted owned by Combat. It does not draw. CardData, IntentStep, EnemyData, and RelicData are Resource files. CardInstance exists only inside a fight. Database loads by explicit res:// path so an export does not depend on DirAccess.get_files_at.

TypeResponsibility
MapCatalog14 rooms, edges, enemy id lists. Not saved.
game.gdHP, gold, deck ids, relics, which screen is pending, offers, save_slot(&"run", …)
BattlePiles, energy, damage formula, intents, four combat relic hooks, to_dictionary / from_dictionary
CardView_get_drag_data and set_drag_preview
DropZone, EnemyView_can_drop_data tests, _drop_data emits the uid
HandViewCenters cards. Not a container, so the hover tween can own position:y

The run dictionary stores ints and strings only: hp, gold, seed, RNG state, deck, relics, cleared ids, open ids, pending screen name, reward and shop offers, and a combat dictionary while it is the player's turn. load_slot returns that dictionary. Continue sets SaveManager.set_value("deck_continue", true), flushes, then SceneRouter.go_to. The game consumes that flag immediately.

Assets and credits

Default art is engine nodes. Attack cards are a red ColorRect, skills blue, powers green, with a Label for the name, cost, type, and rules. Enemies are a tinted ColorRect plus labels. Map rooms are Button nodes and draw_line. No sprite filenames are required, and none are invented here.

Stretch goals

  • A second boss pattern, or a room that offers a card upgrade (+3 damage or +3 Block) instead of a new card.
  • Potion slots: one consumable from the shop, saved as a string id on the run.
  • Seed entry on the menu so two players can climb the same offers. The RNG state is already in the slot.
  • A fan of rotated cards in HandView, and a short screen shake on the player panel using scale rather than moving a container child.
  • Controller focus: End Turn and map buttons already take focus; add a "play highlighted card" action later if you outgrow drag-only play.
