Publishing

Google Play guide

Play wants a signed Android App Bundle built with Gradle. Godot's export page is the authority for JDK 17, the keystore, and Export With Debug. The console forms (App Signing, target API, data safety, rating, listing, tracks) are not in the engine docs. The day that walks them is Day 30. The export itself is built on Day 16.

JDK 17 is the version the Android export page tells you to install. Point Editor > Editor Settings at the Java SDK path and the Android SDK path before Gradle will run. Godot 4.8 and later can install those from the editor. Older 4.x editors use the manual section of the same docs page. Use the docs version that matches your editor.

Type one password for both prompts. Letters and digits. Back up the .keystore file. Losing it means you cannot update that package name with the same upload key.

Play Console forms

External resource

Open play.google.com/console and search each phrase. The form titles move. Nothing below is a Godot menu.

  • Account fee. Registration charges a one-time fee. Read the amount on the signup page.
  • Play App Signing. Search "App Signing". Google can hold the app signing key. The keystore from Godot is then the upload key. You still must keep that upload key. Enroll before the first production release and do not lose the upload keystore.
  • Target API. Search "target API level". Set the preset's Target SDK to the level the console names. Do not freeze an old number into the project and forget it.
  • Data safety. Search "data safety". The Ship Kit writes settings and saves on the device under user://. It does not ship an account system. If you add ads, billing, or a login, the form changes. Answer for the build you upload.
  • Content rating. Search "content rating". Finish the questionnaire. An unfinished rating blocks production.
  • Store listing. Search "store listing". You need a title, short description, full description, an icon, and screenshots. Use the pixel sizes the console shows. They change.
  • Tracks. Search "closed testing" and "production". Internal testing is for you. Closed testing is the gate many new personal accounts must pass: 12 testers opted in for 14 consecutive days has been the published rule, and Google has changed the count before. Read the number on the console. Do not start the clock on a debug AAB.

Billing and ads

Billing is optional. The engine documents the first-party plugin by name: GodotGooglePlayBilling. Install and call it from that page, not from a random mirror. Products are created in the Play Console, then purchased from the plugin. The plugin manual linked from the docs is outside the engine class reference. Treat its steps as external and re-read them when you upgrade Godot.

Android in-app purchases is the docs page. It names the plugin and points at the plugin manual.

External resource

Ads are optional and are not part of the Ship Kit. There is no ads chapter in the engine docs. If you add an ad SDK, the policy is on play.google.com/console (search "ads" and "families"). Update the data safety form. Do not drop an ad network into the template "just in case". A game that does not show ads should not request an ads permission.
