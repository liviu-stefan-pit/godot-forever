Ship Kit: API and layout

Games 6–10 copy C:\GodotProjects\ship-kit and call these autoloads. The names and signatures on this page are the contract. Days 15 and 16 are the click-by-click build. If a script here and a script in those days ever disagree, the scripts below were copied from Day 15 and win.

Folder layout

The template project uses the Mobile renderer. Viewport width 1280 and height 720. Stretch mode canvas_items, aspect expand (set on Day 16). Portrait games change the two size fields and handheld orientation. They do not rename these folders.

Events

Signal bus only. No methods. Connect with Events.score_changed.connect(_on_score_changed). Emit with Events.score_changed.emit(score).

SignalWhen a game emits it
game_startedPlay is pressed. The main menu emits it before go_to.
game_paused(is_paused: bool)ShipPauseMenu when pause opens or closes. SceneRouter.go_to emits false if it has to unpause.
game_over(score: int)The game, when a run ends.
score_changed(score: int)The game, whenever the visible score changes.
achievement_unlocked(id: StringName)The game, after it decides an achievement fired. Steam wiring is Day 29 and stays outside this signal.
settings_changedSettings after set_volume, set_fullscreen, set_locale, or set_value.
toast_requested(text: String)Anyone. toast.tscn shows tr(text). Pass a translation key.

Settings

File user://settings.cfg via ConfigFile. Input remaps in user://input_map.cfg. Volumes are linear 0.0–1.0. Bus argument is &"Master", &"Music", or &"SFX".

MethodBehavior
get_volume(bus: StringName) -> floatLinear 0.0–1.0 from AudioServer.get_bus_volume_linear.
set_volume(bus: StringName, linear: float) -> voidClamps, applies, saves, emits Events.settings_changed.
is_fullscreen() -> boolTrue for fullscreen or exclusive fullscreen.
set_fullscreen(on: bool) -> voidDisplayServer.window_set_mode, saves, emits settings_changed.
get_locale() -> StringTranslationServer.get_locale.
set_locale(locale: String) -> voidTranslationServer.set_locale, saves, emits settings_changed.
get_value(section: String, key: String, default: Variant = null) -> VariantExtra config keys. The menus use section ui, key return_scene.
set_value(section: String, key: String, value: Variant) -> voidWrites, saves, emits settings_changed.
save_settings() -> voidWrites user://settings.cfg.
save_input_map() -> voidEvery action, events stored with var_to_str.
load_input_map() -> voidCalled from _ready. Missing file means keep the editor map.

Config sections the kit writes: audio (bus name to linear float), video/fullscreen, general/locale, ui/return_scene.

SaveManager

const FORMAT_VERSION: int = 1. Slots are user://saves/<slot>.json. The write is atomic: .tmp, then DirAccess.rename_absolute after removing the old file. Envelope:

{
    "format": 1,
    "saved_at": 0,
    "data": {}
}

saved_at is unix time from Time.get_unix_time_from_system, stored with int(). JSON still returns numbers as floats. Cast counters at the call site with int(). Do not store integers past 2^53. Idle-clicker magnitudes are strings.

The profile is user://profile.json with format and values. set_value marks it dirty and writes about 1 second later. flush writes now. flush also runs on NOTIFICATION_WM_CLOSE_REQUEST (then quit, because auto-accept quit is off), NOTIFICATION_APPLICATION_PAUSED, NOTIFICATION_APPLICATION_FOCUS_OUT, and NOTIFICATION_WM_GO_BACK_REQUEST.

MethodBehavior
has_slot(slot: StringName) -> boolTrue if that json file exists. Names containing /, \, or .. are rejected.
save_slot(slot: StringName, data: Dictionary) -> boolFalse if the name is rejected or the rename fails.
load_slot(slot: StringName, default: Dictionary = {}) -> DictionaryA duplicate of data, or a duplicate of default if the file is missing or the format integer does not match.
delete_slot(slot: StringName) -> voidRemoves the file if it exists.
get_value(key: String, default: Variant = null) -> VariantProfile lookup. Not the same method as Settings.get_value. Settings takes a section.
set_value(key: String, value: Variant) -> voidProfile write, debounced 1 second.
flush() -> voidWrites the profile immediately.

Games store a run with SaveManager.save_slot(&"run", {...}) and a small flag with SaveManager.set_value("best_score", n). Read that flag back with int(SaveManager.get_value("best_score", 0)).

Audio

Eight AudioStreamPlayer nodes on bus SFX. Two music players, MusicA and MusicB, on bus Music. The autoload's process mode is Always, and music tweens use Tween.TWEEN_PAUSE_PROCESS, so a fade continues while the tree is paused. play_sfx's volume_db is a per-sound offset. It is not the bus slider.

MethodBehavior
play_sfx(stream: AudioStream, volume_db: float = 0.0, pitch_scale: float = 1.0) -> voidNext pooled player. Null stream returns.
play_sfx_varied(stream: AudioStream, pitch_spread: float = 0.1, volume_db: float = 0.0) -> voidPitch 1 ± pitch_spread, clamped to 0.01–4.
play_music(stream: AudioStream, fade_time: float = 0.8) -> voidCrossfade. Same stream already playing is left alone. Null calls stop_music.
stop_music(fade_time: float = 0.8) -> voidFades the active player to -80 dB and stops it.

SceneRouter

const MAIN_MENU_SCENE: String = "res://ui/main_menu.tscn"

const GAME_SCENE: String = "res://game/game.tscn"

signal transition_finished

A full-screen ColorRect named Fade is created in _ready. go_to ignores a second call while a fade is running. If the tree is paused it unpauses and emits Events.game_paused(false) before the swap. It waits for SceneTree.scene_changed before fading in. Color is assigned as a whole value. Do not write color.a on the property and expect it to stick.

MethodBehavior
go_to(scene_path: String, fade_time: float = 0.25) -> voidFade out, change_scene_to_file, fade in, emit transition_finished.
reload_current(fade_time: float = 0.25) -> voidgo_to the current scene's scene_file_path.
quit_game() -> voidSaveManager.flush(), then get_tree().quit().

UI scenes games reuse

FileContract for later days
ui/main_menu.tscnMain scene. Buttons %PlayButton, %SettingsButton, %CreditsButton, %QuitButton. Play emits game_started and go_to(GAME_SCENE).
ui/pause_menu.tscnclass_name ShipPauseMenu. Instance it under game.tscn. process_mode = Always. Methods toggle(), open_menu(), close_menu(). Listens for the pause action. Emits Events.game_paused.
ui/settings_menu.tscnSliders call set_volume. Back uses Settings.get_value("ui", "return_scene", MAIN_MENU_SCENE). Remap calls save_input_map.
ui/credits.tscnShows Engine.get_license_text() and names from Engine.get_copyright_info(). First editor run writes res://licenses/GODOT_LICENSE.txt if it is missing.
ui/toast.tscnLayer 90. Connects to toast_requested. Instance it in scenes that should show toasts.
ui/safe_area.gdOn a Full Rect Control. Sets offsets from DisplayServer.get_display_safe_area, scaled into the stretched viewport.
i18n/translations.csvHeader keys,en,es,de,fr,pt_BR,ru,zh_CN. UI keys start with UI_. Game keys use CLICKER_, BH_, MERGE_, DECK_, DIGGER_. Button Text is the key. Call tr("KEY") from code.

Input actions defined on the template: move_left, move_right, move_up, move_down, jump, dash, attack, interact, pause, confirm, cancel. Leave the built-in ui_* actions in place. They move focus.

Android package on the template: com.yourname.shipkit. Each copied game replaces yourname and the last segment (idleclicker, bulletheaven, physicsmerge, deckbuilder, deepdigger). Release exports uncheck Export With Debug. Keystore password equals key password.
