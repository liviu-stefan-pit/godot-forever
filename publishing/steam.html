Publishing

Steam guide

Steam sells and updates a Windows build you already know how to export. Godot does not upload that build. Steamworks, store images, depots, and SteamCMD are outside the engine docs. GodotSteam achievements are an addon, also outside the engine docs. The click-by-click day is Day 29.

--export-releaseWindows Desktop preset

What is actually a Godot step

  1. Install export templates that match the editor: Editor > Manage Export Templates....
  2. Preset name stays Windows Desktop unless you change the command to match. Architecture x86_64.
  3. Export with Export With Debug unchecked, or from PowerShell with --headless --export-release. The docs spell the flag --export-release, not a debug export.
  4. Output folder is outside res://, for this course C:\GodotProjects\ship-kit-build\windows\. Copy GODOT_COPYRIGHT.txt beside the exe (licenses).
  5. Launch that exe once before you upload it. Then launch the same build from the Steam client after upload. Those are different tests.

Controller support you already built is the Godot part of "Steam Input" and Deck play: actions move_*, pause, confirm, cancel, and focus via ui_accept plus grab_focus(). The docs for pads are Controllers, gamepads, and joysticks and Controller features.

Steamworks, in the order you need it

External resource

Everything in this section is verified on partner.steamgames.com. Search the phrases below. Buttons move. Do not trust a screenshot from a blog.

  • Account and fee. Search "getting started". The partner account is tied to a Steam user. Creating an app charges a fee per app. Read the current amount on the partner site before you pay. Day 16 only opens the account. Day 29 pays for the app when you are ready to have an app id.
  • App id. Search "create a new application". Write the numeric app id down. You need it for depots and for steam_appid.txt if you use GodotSteam in the editor.
  • Depots. Search "depots". A depot is a pile of files for one OS. This course uploads one Windows 64-bit depot. The content root is the folder that contains ShipKit.exe, not the Godot project folder.
  • Store page. Search "store page" and "graphical assets". You will be asked for capsules, a header, screenshots, and a short description. Copy the pixel sizes from that checklist the week you upload. They change. Do not ship a capsule at a size you remember from an older template.
  • SteamCMD. Search "SteamCMD". Install the tool from the instructions on the partner site. Upload with an app build script (SteamPipe). A typical script points contentroot at the export folder and maps LocalPath * onto the depot. Compare your script to the sample the partner docs show that week. The app id and depot id in the script must be yours, not the zeros in a sample.
  • Branches. Upload to a beta branch first. Set the build live on default only after you have launched it from the Steam client.
  • Steam Deck. Search "Steam Deck". The review looks at text size, controller-only play, and a 1280×800-class display. Your stretch mode canvas_items plus expand is the Godot half. The Deck checklist itself is on the partner site. Do not mark Verified in the store until that checklist says you can.

GodotSteam achievements

External resource

GodotSteam is not in the engine. The engine docs do not list its methods. Download the addon that matches your Godot minor version and read the class reference that ships with it. Search "GodotSteam" from the addon page you trust, and define the achievement API names in Steamworks first (partner site, search "achievements"). Names are case-sensitive strings you invent in Steamworks, such as ACH_WIN.

The sequence that has been stable is: initialize Steam, set the achievement by that string, store stats. Method names differ across addon versions. This sketch is the shape, not a promise that steamInit is spelled this way in the build you downloaded. If the addon reference uses another name, use that name.

Put the numeric app id in steam_appid.txt at the project root while you test in the editor. Steamworks documents that file. Do not ship a text file full of secrets. An app id is not a password, and it is still not something to hard-code into a screenshot.

The Ship Kit signal Events.achievement_unlocked(id) is the game-side event. GodotSteam is the only thing that should talk to Steam. Game scripts emit the signal. One place listens and calls the addon. When you remove the addon, the game still compiles.
