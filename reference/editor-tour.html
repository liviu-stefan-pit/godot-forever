Every part of the Godot 4 editor, labelled, with the default layout. Keep this page open in a second tab on Day 1 and whenever you ask yourself "where is that button?". Each area has a table: control, what it does, shortcut.

2. The Project Manager

The first window you see when you launch Godot (and the one you return to with Project > Quit to Project List). It is a separate process from the editor.

ControlWhat it does
Projects tabList of known projects. Double-click one to open it in the editor. Use the filter bar to search; tag:name filters by tag.
Asset Library tabDownload templates and demos. First visit shows Go Online: the engine never touches the internet until you opt in (Network Mode in Settings).
Create (top-left)New project dialog: Project Name, Browse for a folder (green tick = empty folder), optional Create Folder toggle, renderer choice (Forward+, Mobile, Compatibility; changeable later), optional version control, then Create.
ImportSelect an existing folder or its project.godot file (or a zip file, which Godot extracts) to add it to the list.
Manage TagsAdd tags to a project (plus button, type name, OK). Tags travel with the project folder. A tag disappears from the list when no project uses it any more (restart the Project Manager).
Dropdown next to EditEdit in recovery mode: use after crashes. Disables tool scripts, editor plugins, GDExtension addons, automatic scene restoring and running the project. Back up first. Godot normally offers it automatically after a crash.
Settings (top-right)Editor language (default = system language), theme and color preset, display scale, network mode, directory naming convention for auto-created folders.

File browser inside Create/Import: back/forward arrows, up arrow (parent folder), refresh, favorite/unfavorite, show/hide hidden folders, grid/list view, new folder, and left-side Favorites and Recent lists.

Save before you run

By default Godot saves scenes and scripts when you press Run (Run > Auto Save > Save Before Running in Editor Settings is on). If you turn that off, unsaved changes will not appear in the running game.

The renderer name and current dropdowns (for example Forward+, Mobile, Compatibility) may appear next to the play buttons; the dropdown changes the renderer used when running from the editor (name may differ slightly by version).

"Main scene" vs "current scene"

F5 runs the project's main scene (Project > Project Settings > Application > Run > Main Scene). F6 runs whichever scene tab is open. To change the main scene quickly, right-click a .tscn file in the FileSystem dock and choose Set As Main Scene.

Windows console gotcha

If you launch Godot with its system console enabled and the editor suddenly "freezes", you have clicked inside the console window, which enters Windows selection mode. Click the console and press Enter.

Half Resolution renders the 3D viewport at half resolution and can be up to 4x faster on high-DPI screens; it is the first thing to try if the editor feels slow.

Black 3D viewport when running?

A 3D scene shows nothing at runtime without a Camera3D. The editor's preview sun and environment disappear at runtime too: add a DirectionalLight3D and a WorldEnvironment to the scene.

11. The Node tab: Signals and Groups

A tab next to the Inspector. It has two sub-tabs for the selected node.

Sub-tabWhat it shows / does
SignalsList of signals the node can emit. Double-click a signal (e.g. pressed) to open the connection window. Simple mode connects to a node that already has a script and generates the receiver method, named by convention _on_<node_name>_<signal_name>; Advanced (bottom-left of the window) lets you connect to any node/built-in method and bind extra arguments. Click Connect to finish; Godot jumps to the Script workspace where the new method has a connection icon in the left margin. Editor-made connections are shown there; connections made in code are not. If you use an external editor, the generated code may not appear, so connect in code instead.
GroupsSelect a node, click the + button, name the group in Create New Group (optionally tick Global to make it project-wide with a description). Tick the checkbox next to a group to put the selected node in it. Groups appear under Scene Groups or Global Groups. Global groups are also managed in Project > Project Settings > Globals > Groups (the docs describe a Groups tab in the Globals dock).

The docs sometimes say "Signals dock" and "Groups dock"; the course says Node tab > Signals and Node tab > Groups.

17. The Game workspace (embedded game window)

When you press Run, the Game workspace represents the running project. The game always runs in a separate process: if it crashes, the editor survives. Three embedding modes:

ModeBehaviour
Floating window (default)Game runs in its own window with a Game bar on top; clicking the Game workspace button focuses that window.
Main windowGame runs inside the editor; clicking Game switches to that tab.
DisabledGame runs like an exported build; there is no Game bar and no node picking.

Configure it in the dropdown in the top-right of the Game bar: Embed Game on Next Play and Make Window Floating on Next Play. Window sizing options (affect floating and main-window modes): Fixed Size (default, the project's viewport size or the window width/height override), Keep Aspect Ratio, Stretch to Fit (matches a non-embedded run).

18. Customizing and resetting the layout

  • Resize a dock or panel: drag its edge.
  • Move a dock: click the three vertical dots at the top of the dock and choose a new location, or Make Floating to turn it into its own window. Close a floating dock with its X (or Alt+F4 while it is focused) to put it back.
  • Split the script or shader editor into its own window with the button in its top-right corner (Windows, macOS, Linux; not in Single Window Mode).
  • Save a layout: arrange the docks, then Editor > Editor Layouts > Save, type a name, Save. Saved: dock moves and sizes, floating docks, FileSystem dock mode/sort/selected and unfolded paths.
  • Load / delete: Editor > Editor Layouts lists saved layouts and Default (hard-coded, cannot be removed); use Delete to remove one.
  • Reset everything: Editor > Editor Layouts > Default. If you ever overwrote the default by saving a layout named Default (case-sensitive), delete that Default layout to get the factory one back. Layouts are stored in editor_layouts.cfg in the editor config folder.
If the editor misbehaves

Crash on open? Use Edit in recovery mode in the Project Manager. Slow or flickering? See Troubleshooting. Strange cached state? Close the editor and delete the project's .godot folder; it is regenerated on the next open (see the glossary entry for .godot folder).
