How to run any snippet

Create a project, add a Node as the root of a scene, right-click it in the Scene dock → Attach Script, press Ctrl+A in the script editor and paste the listing over the whole file, save, then press F6 (Run Current Scene). Output appears in the Output panel at the bottom. All listings use 4 spaces for indentation (set Editor > Editor Settings > Text Editor > Behavior > Indent > Type to Spaces).

2. A file is a class

Every .gd file is a class that implicitly extends RefCounted unless you write extends. A script attached to a node is that node's behaviour: the node is an instance of the script class. A script can be referenced by path (load("res://x.gd"), preload(...)) or, if it declares class_name, by a global name that is available in every other script and in the editor's "Create New Node" dialog.

3. Syntax basics

  • Indentation defines blocks (like Python). Do not mix tabs and spaces in one file. The course uses 4 spaces. Colons end if, for, while, match, func, class.
  • Comments: # to end of line; ## documentation comments; #region Name / #endregion make foldable regions (no space after #).
  • Semicolons are optional statement separators; parentheses around conditions are optional.
  • Line continuation: a trailing \, or just break lines inside (), [], {}.
  • One-liners: func square(a): return a * a, if x: return.
  • Identifiers: letters, digits, _; not starting with a digit; case-sensitive; most Unicode letters allowed.
  • Literals: 12_345, 0xFF, 0b1010, 3.14, 5e-3; strings "x", 'x', """multi-line""", raw r"C:\path"; &"name" is a StringName; ^"Path/To/Node" is a NodePath; $Path and %Unique are node shortcuts.
  • Escapes: \n \t \r \" \' \\ \uXXXX \UXXXXXX.

Reserved words

if elif else for while match when break continue pass return class class_name extends is in as self super signal func static const enum var breakpoint preload await assert void and the constants PI TAU INF NAN. The old coroutine keyword is still reserved but is not used: use await. Built-in type names and the operators in, not, and, or are reserved too.

4. Operators

Precedence is the table order below, highest first. Every binary operator is left-associative, including **: 2 ** 2 ** 3 is (2 ** 2) ** 3, unlike Python. The ternary if/else is right-associative. An assignment is not an expression: you cannot write if (a = b) or chain a = b = 1.

Both % and fmod() truncate, so the remainder keeps the sign of the dividend. Use posmod() / fposmod() for a non-negative remainder. % is also string formatting.
+ -+ adds numbers or concatenates String. It does not coerce: "hp " + str(n), not "hp " + n.

5. Control flow and match

if / elif / else, while, for, break, continue, pass, and return behave like Python. Parentheses around the condition are optional. A semicolon can separate statements on one line and is almost never wanted. assert(cond) or assert(cond, "message") runs in debug builds only and pauses the game when you run from the editor. Do not put side effects in an assert: release exports skip the expression entirely.

  • for x in array binds each element. Assigning to x does not write back. Mutating an object through x does. To replace elements, iterate for i in array.size().
  • for key in dictionary iterates keys, not pairs. Read the value with dictionary[key].
  • for i in range(n), range(start, end), range(start, end, step). End is exclusive. for i in 3 is range(3). for i in 2.2 is range(ceil(2.2)). range does not allocate an array.
  • for c in "Hello" yields characters. A typed loop variable is allowed: for name: String in names.
  • There is no for/else and no try/except. Validate, return a result, or assert.

match is a strict pattern switch. It does not fall through (the Godot 3 continue-inside-match behaviour is gone). Patterns are tested top to bottom; the first hit runs and then execution leaves the match. match is stricter than ==: 1 does not match 1.0. String and StringName do match each other ("hello" matches &"hello").

6. Functions, lambdas, Callable

Functions belong to the class. Lookup order is local, then member, then global. self is the instance and is optional for member access; it is not a declared first parameter (unlike Python). A function with no return returns null. A typed non-void function must return on every path. void may return early but must not return a value. Defaults must trail required parameters. A one-line function is func square(a: int) -> int: return a * a.

Naming a method without calling it produces a Callable (var step: Callable = add1). Call it with step.call(1). You cannot write step(1): the language forbids the call operator on Callable so that ordinary calls stay fast. callable.bind(extra) appends arguments. callable.callv(array) unpacks an array. There is no spread syntax at the call site (f(...args) is a parse error).

A lambda is var double := func(x: int) -> int: return x * 2, then double.call(4). The name in func my_lambda(x): is only for the debugger. Lambdas capture locals by value, once, at creation. Reassigning the outer local does not update the capture, and assigning inside the lambda shadows it (warning CONFUSABLE_CAPTURE_REASSIGNMENT). Arrays, dictionaries, and objects are references, so mutating their contents is visible outside; reassigning the variable is not. Lambdas cannot be static. An explicit return is required to return a value from a lambda.

static func has no self and no instance members. It can read static variables. Since 4.5, a rest parameter collects extra arguments: func sum(first: int, ...values: Array) -> int. At most one, and it must be last. You cannot type it as Array[int] yet; the rest type is a plain Array. On 4.3/4.4, take an Array parameter instead.

CONNECT_ONE_SHOT, CONNECT_DEFERRED, and CONNECT_PERSIST are connection flags on Object. CONNECT_DEFERRED runs the callback on idle, which is the safe way to react to a signal that fires in the middle of physics or during a script change.

7. Classes, super, memory

One script file is one class. Without extends it extends RefCounted and is freed when nothing references it. Node and plain Object are not reference-counted: queue_free() (nodes, end of frame, children included) or free() (immediate; do not use it on a node you are still standing on). weakref(obj) does not keep a RefCounted alive; weak.get_ref() returns the object or null. is_instance_valid(obj) is the check for an object that may already have been freed.

class_name Foo registers a global type. extends "res://other.gd" and extends "res://other.gd".Inner inherit from a file or an inner class. Single inheritance only. super(args) calls the same method on the base class. super.other(args) calls a different base method. If the base _init takes arguments, the derived _init must exist and call super(...). _init runs after member initializers. static func _static_init() -> void runs once when the class loads, after static variables, with no arguments and no return value.

Do not override native methods such as get_class() or queue_free(). The NATIVE_METHOD_OVERRIDE warning is an error by default. Virtual callbacks (_ready, _process, _physics_process, names that the docs mark virtual) are the supported extension points.

Inner classes use the class keyword and Inner.new(). preload("res://x.gd") is a compile-time constant; load("res://x.gd") reads at the call. Instantiate a script with .new(), a scene with packed.instantiate() then add_child().

@abstract is 4.5+

An @abstract class cannot be instantiated or attached to a node. An @abstract func has no body. On 4.3 and 4.4, use a normal base class and a method that returns a sentinel.

8. Properties

A property is a variable with get and/or set. Unlike the Godot 3 setter syntax, these blocks run even for assignments inside the same class, with or without self.. Reading or writing the property name inside its own getter or setter touches the stored value directly, so it does not recurse. Calling another function that then assigns the property does recurse. The initializer writes the stored value directly and does not call the setter. That includes @export and @onready initialization.

The split form reuses methods: var health: int: get = get_health, set = set_health. Both sides must use the same style. Inline getters and setters cannot carry their own type hints; the setter argument and getter result follow the variable type. External setter functions may be typed and must match or be wider.

@export shows the property in the Inspector. The value is stored in the scene or resource and applied after _init and before @onready. Hints (all on @GDScript):

Do not put @onready and @export on the same variable. @onready overwrites the exported value when _ready runs. That warning (ONREADY_WITH_EXPORT) is an error by default.

9. Signals

A signal is a list of Callables. Declare signal health_changed(current: int, maximum: int). Emit with health_changed.emit(health, maximum). Connect with health_changed.connect(_on_health_changed). Disconnect with disconnect. is_connected avoids a double connection, which would call the method twice. Argument names in the declaration are documentation for the Signals dock; the engine does not force you to emit that many values, so emit what the callback expects.

In the editor: select the node, open the Node tab (next to the Inspector), Signals, double-click the signal, pick the target. In code, prefer the Callable form above. A custom signal on an autoload that another script emits can be marked @warning_ignore("unused_signal").

Signal and Callable are real types. var pressed: Signal = $Button.pressed and var rotate: Callable = $Sprite2D.rotate pass them around. await health_changed resumes with the arguments: one argument returns that value, several return an Array, none returns null.

10. await

await turns the current function into a coroutine and returns control to the caller immediately. When the signal is emitted, or when the awaited coroutine returns, execution continues on the next line. If you need the return value, the caller must await too. Calling a coroutine and ignoring the result is legal and does not suspend the caller. await on an ordinary value returns it immediately and does not make the function a coroutine. Returning a signal from a plain function makes the caller await that signal.

There is no function-state object to inspect or resume by hand. That is deliberate: a function typed as -> int cannot secretly return a suspended state.

SceneTree.create_timer(seconds).timeout is the delay. process_frame and physics_frame are signals on the tree. create_timer defaults to process_always = true, so it still finishes while the tree is paused; pass false if a pause should freeze the wait. After every await, the node may have been freed or the scene changed. Check is_instance_valid or is_inside_tree() before touching nodes.

12. Built-in types

Built-ins are value types: assignment and argument passing copy them. Object, Array, Dictionary, and packed arrays are references. Copy an array or dictionary with duplicate() (duplicate(true) is deep). Only Object can be null. A typed Vector2 is never null; it default-constructs.

A value is not checked against the enum at runtime.

13. String formatting

Three tools, in the order the docs present them. % is printf-style. String.format() substitutes {name} or {0}. + concatenates strings only.

SpecifierMeaning
%sSame conversion as str(). The default choice.
%cOne Unicode character from a code point or a one-character string.
%d %o %x %XDecimal, octal, hex. Floats are floored.
%fFloat. %.2f is two decimals. %10.3f pads to width 10.
%vAny int or float vector, coordinates in parentheses, each formatted like %f.

Several placeholders take an array: "%s has %d" % ["mobs", 3]. Modifiers before the type: + forces a sign, a number sets width, a leading 0 zero-pads, - pads on the right, * reads the width from the next value ("%0*d" % [2, 3] prints 03). A literal percent is %%. There is no Python %(name)s form in GDScript.

"Waiting for {who}".format({"who": "Godot"}) and "{0} / {1}".format([hp, maximum]). "{} {}".format(["a", "b"], "{}") uses empty braces when you pass the placeholder string. This is the closer equivalent of an f-string or of C# $"", with none of the interpolation syntax.

14. Lifecycle order

Member initialization, then the tree. From the GDScript reference, for a node:

  1. The variable starts as null (objects and untyped) or as the type default (0, false, Vector2()).
  2. Initializers run top to bottom. @onready initializers are skipped until step 5.
  3. _init runs. Children of a scene are not in the tree yet. $Path is not valid here.
  4. If this is a scene or resource instance, @export values from the disk file are assigned (they do not call setters).
  5. @onready initializers run.
  6. _ready runs.

Tree order, from the SceneTree tutorial and Node:

  • _enter_tree is pre-order: parent, then children. It runs every time the node enters the tree. The node is inside the tree, but siblings and later children may not have entered yet.
  • _ready is post-order: children, then parent, so a parent can use its children. It runs once. Re-adding a node does not call _ready again unless you called request_ready() before the re-add. The ready signal is emitted after _ready.
  • _exit_tree is the reverse of enter order (children after the parent has started exiting, bottom to top as the docs describe the exit notification).
  • _process and _physics_process follow tree order. A lower process_priority runs first. Physics code belongs in _physics_process; the tick is fixed (default 60 Hz) and delta is seconds. Visuals and UI belong in _process.

Node.NOTIFICATION_ENTER_TREE and NOTIFICATION_READY are the same moments, delivered to _notification. Prefer the named virtual methods unless you are handling several notifications in one place.

15. $ and %

$UI/Score is get_node("UI/Score"), resolved from this node. $"Name With Spaces" quotes unusual names. ^"UI/Score" is a NodePath literal, not a lookup. % is the unique-name shorthand: %ScoreLabel is get_node("%ScoreLabel") and searches the unique names of this scene. In the Scene dock, right-click the node and choose Access as Unique Name. The node shows a % prefix. Prefer % for UI that moves during layout work; a renamed or reparented unique node does not break the script. Prefer @onready var score: Label = %ScoreLabel over calling get_node inside _process.

get_node fails if the path is wrong or the node is not ready. get_node_or_null returns null instead. has_node tests. Unique names and $ both require the node to be inside the tree, which is why they belong in @onready or _ready, not _init.

16. Style

The official GDScript style guide follows PEP 8 and tells you to indent with tabs, which is also the editor default. 17. Typing and performance

GDScript is gradually typed. A declaration without a type is a Variant. Writing : Variant is the same thing and cannot be inferred with :=. Typed code uses faster opcodes when the compiler knows both operands, and it makes the completion list show the members of the real class instead of every method on Variant.

Safe lines (the ones the analyzer can prove) are the ones that get those opcodes. An untyped call, an untyped operator, or a bare $Node is an unsafe line: $Node is typed as Node, so write @onready var sprite: Sprite2D = $Sprite or $Sprite as Sprite2D. Enable UNTYPED_DECLARATION, INFERRED_DECLARATION, and the UNSAFE_* warnings under Project > Project Settings > Debug > GDScript (turn on Advanced Settings) when you want the editor to nag. The course keeps the default warnings and writes types anyway.

Casting with as to a wrong object type yields null, which is a useful guard: var player := body as Player then if player == null: return. A failed cast of a built-in is an error, not null.

What actually matters for frame time, in order: algorithm, number of nodes, physics shape count, and draw calls. Typing will not rescue a thousand _process scripts doing get_node. It does remove a class of bugs and speeds up tight GDScript loops. Further JIT/AOT work is described in the static typing page as planned, not as something you enable.
