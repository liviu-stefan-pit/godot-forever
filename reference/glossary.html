Reference · Vocabulary

Glossary

Godot words you will meet in the editor and in GDScript, in alphabetical order, with the nearest idea from engines and languages you may already know. Definitions follow the Godot 4 docs. Equivalents are orientation, not a promise that the APIs match.

ReferenceA to Z
TermMeaningNearest equivalent
ActionA named input in the Input Map, such as jump. Several keys, mouse buttons, or pad buttons can feed one action. Read it with Input.is_action_pressed.Unity Input Action, Unreal Action Mapping.
AnchorThe edges of a Control, as fractions of the parent rectangle. Offsets are pixels from those edges. Containers ignore child anchors and use size flags instead.Unity anchors on a RectTransform. Unreal anchors on a canvas slot.
AnimationPlayerA node that stores and plays keyframed clips by name. play(), speed_scale, signal animation_finished.Unity Animator clip playback, Unreal Animation Sequence player, without a blend graph.
AnimationTreeBlends AnimationPlayer clips through a state machine or blend tree. active must be on, and anim_player must point at the player.Unity Animator Controller, Unreal Animation Blueprint state machine.
AnnotationA @ token that changes the next declaration: @export, @onready, @tool, @warning_ignore. Listed on @GDScript.C# attributes, Python decorators, Java annotations.
Area2D / Area3DA collision object that detects overlaps and can override gravity or damping. It does not block movement. Signal body_entered.Unity trigger collider, Unreal overlap volume.
AssetLibThe workspace button that opens Godot's asset library inside the editor. This course stays on built-in nodes and CC0 packs, so you can ignore it until you go looking.Unity Asset Store window, Unreal Fab / Marketplace browser.
AutoloadA script or scene the engine instances before the main scene and keeps alive. Registered in Project Settings > Globals > Autoload. The name becomes a global.A manually created singleton, Unity RuntimeInitializeOnLoad, Unreal GameInstance subsystem.
AwaitPauses the current function until a signal fires or a coroutine returns, then continues. The caller must await too if it needs the return value.Python / JS / C# await. Replaces the Godot 3 coroutine keyword.
BasisThe 3×3 matrix inside a Transform3D: rotation and scale, three axes x, y, z. Position lives in origin, not in the basis.The upper-left 3×3 of a 4×4 world matrix.
BusAn audio mixing channel. The default layout has Master. This course adds Music and SFX. Volume is decibels on the bus, not a linear slider, until you convert it.Unity Audio Mixer group, Unreal Sound Class / Submix.
CallableA bound function value. Referencing a method without calling it creates one. Invoke with call(), not with parentheses. Signals store callables.C# delegate, JS function value, Python function object.
Camera2D / Camera3DThe node that defines the view. A Camera2D is current when enabled. A Camera3D is current when current is true. Only one current camera per viewport.Unity Camera, Unreal CameraActor.
CanvasItemBase of everything drawn in 2D, including Node2D and Control. Owns visible, modulate, z_index, y_sort_enabled, and texture_filter.A 2D drawable. No single Unity or Unreal type covers both sprites and widgets.
CanvasLayerA 2D draw layer with its own transform. Higher layer draws on top. HUD and menus sit here so a moving Camera2D does not drag them.Unity Screen Space - Camera canvas, Unreal UMG on a separate viewport layer.
CharacterBody2D / 3DA physics body that detects collisions and does not simulate forces. You set velocity and call move_and_slide().Unity CharacterController, Unreal Character Movement in flying or walking mode that you drive yourself.
class_nameRegisters the script as a global type so other scripts and the Create New Node dialog can use it. Names must be unique in the project.A public class declaration. Unity MonoBehaviour class name, with editor registration included.
Collision layerThe bits in collision_layer: which layers this object is on. Default is layer 1. This course names layer 1 world, 2 player, and so on.Unity Layer, Unreal Object Type on a collision channel.
Collision maskThe bits in collision_mask: which layers this object scans. If the other object is not on a scanned layer, this object ignores it.Unity Layer Collision Matrix row, Unreal collision response channels.
CollisionShape2D / 3DA child node that holds a Shape2D or Shape3D resource. The parent body or area does not collide until at least one shape is assigned. Do not scale the node; edit the shape.Unity collider component, Unreal collision component.
Compatibility rendererThe Godot 4 renderer aimed at older GPUs and the widest hardware. The course uses Mobile or Compatibility for Android, and Forward+ for the Part 1 3D games.A low-end graphics API path, roughly Unity's older built-in pipeline on GLES.
ConfigFileAn INI-style file of sections and keys. The course settings autoload stores user://settings.cfg with it.Python ConfigParser, Unity PlayerPrefs if you squint, an .ini.
ContainerA Control that positions its children. Box, grid, margin, scroll, center, panel, and aspect-ratio containers are the ones this course uses. Children use size flags, not anchors.Unity Horizontal/Vertical Layout Group, Unreal Horizontal/Vertical/Grid boxes.
ControlBase class of all GUI. Rect is anchors plus offsets. mouse_filter decides whether clicks pass through. focus_mode decides keyboard and pad focus.Unity UI RectTransform plus a widget, Unreal UWidget.
CSGConstructive solid geometry: boxes, spheres, and combiners that union or subtract. The class pages say it is for prototyping. Moving CSG during play is expensive; bake to a mesh when the shape settles.Unreal BSP brushes, Unity ProBuilder in a pinch.
DeltaSeconds since the previous _process or _physics_process call. Multiply speeds by delta so motion does not depend on frame rate. Physics delta is the fixed step, default 1/60.Unity Time.deltaTime, Unreal DeltaTime.
DockA panel of the editor. Scene dock is the node tree (top-left). FileSystem dock is res:// (bottom-left). Inspector is on the right. The Node tab beside the Inspector holds Signals and Groups.Unity windows (Hierarchy, Project, Inspector). Unreal panels.
Export@export stores a property on the scene or resource and shows it in the Inspector. The value is applied after _init and before @onready. Not the Godot 3 keyword placed before var.Unity [SerializeField], Unreal UPROPERTY(EditAnywhere).
Export templateThe prebuilt engine binary used to package a game. It must match the editor version. Install from Editor > Manage Export Templates. A mismatch is the usual reason an export preset fails.A platform build target shipped separately from the editor.
FileAccessReads and writes files. FileAccess.open(path, FileAccess.WRITE). Replaces the Godot 3 file type you constructed by hand. Writes to res:// fail in an exported game; use user://.Python open, C# File, Godot 3's old file API.
FileSystem dockBottom-left panel listing the project as res://. Drag a scene onto the viewport or onto a node to instance it. This is not the operating system's file dialog.Unity Project window, Unreal Content Browser.
FocusWhich Control receives keyboard and joypad UI events. focus_mode is None, Click, or All. The ui_* actions move focus. A mouse-only button is invisible to a gamepad until focus works.Unity EventSystem selected object, Unreal UMG focus.
Forward+The clustered-forward renderer. Default for the Part 1 3D games. Heavier than Mobile, supports more lights.A modern forward clustered renderer. Not Unity URP and not HDRP; do not expect those feature lists.
GDScriptGodot's indented scripting language. A file is a class. Typed optional. No exceptions. This course uses only GDScript, on the standard (non-.NET) editor build.A Python-shaped language that is not Python. Closer to a game scripting layer than to C#.
GridMapPaints cells from a MeshLibrary on a 3D grid. Days 12 and 13 build the dungeon with it. cell_size must match the meshes.Unity tile palette in 3D, Unreal geometry brushes or a mesh scatter on a grid.
GroupA named set of nodes. add_to_group("enemies"), is_in_group, get_tree().get_nodes_in_group. The Node tab has a Groups sub-tab. Course groups: enemies, player, pickups, projectiles, persist.Unity tags plus FindGameObjectsWithTag, Unreal Gameplay Tags used as a query.
Input MapProject Settings > Input Map. Where actions are born. Deadzones for sticks live on the action. Course names: move_left, move_right, move_up, move_down, jump, dash, attack, interact, pause, confirm, cancel.Unity Input Actions asset, Unreal Project Settings > Input.
InspectorThe right-hand dock. Shows the selected node's properties. Groups match the class (Collision, Transform). Exported script variables appear here after you save the script.Unity Inspector, Unreal Details panel.
JSONJSON.stringify and JSON.parse_string. The spec has one number type, so every number comes back as float. Cast counters with int(). Vector2 and Color are not JSON types.Any JSON library. The float rule surprises people coming from JSON.parse in JS, which has the same single number type.
KeystoreThe file that signs an Android package. keytool creates it. The docs require the keystore password and the key password to be the same. Losing it means you cannot update the Play listing.A Java keystore. Unity and Unreal Android exports ask for the same file.
load / preloadpreload("res://x.tscn") resolves at parse time and can be a const. load reads when called. Both return a Resource.A static asset reference versus Resources.Load / Unreal soft load.
Main sceneThe scene F5 runs. Set it in Project Settings > Application > Run > Main Scene, or when the editor asks on the first F5. F6 runs the open scene instead.Unity's scene in Build Settings index 0, Unreal default map.
MeshInstance3DDraws a mesh resource. A BoxMesh or an imported glTF mesh goes in the mesh property.Unity MeshFilter plus MeshRenderer, Unreal Static Mesh Component.
Mobile rendererThe renderer this course uses for Part 2 2D games and discusses for Android. Fewer 3D features than Forward+, cheaper on phones.A mobile-oriented rendering backend. Pick it in Project Settings > Rendering > Renderer.
Mouse filterControl.mouse_filter. Stop eats the click, Pass lets it through after handling, Ignore skips the control. A full-screen ColorRect left on Stop blocks the world and the buttons under it.Unity raycast target, Unreal visibility of hit-test.
move_and_slideCharacterBody2D.move_and_slide() and the 3D twin. No arguments. Uses the velocity property, slides along walls, and reports floor, wall, and ceiling.Unity CharacterController.Move, Unreal AddMovementInput plus the movement component's slide.
MultiMeshA resource of many transforms of one mesh. MultiMeshInstance2D draws them in one pass. Day 21 uses this for the crowd.Unity DrawMeshInstanced, Unreal Instanced Static Mesh.
NavigationAgentNavigationAgent2D or NavigationAgent3D. Set target_position, read the next path point, or connect velocity_computed when avoidance is on. Needs a baked region in the tree.Unity NavMeshAgent, Unreal AI Move To on a NavMesh.
NodeOne object in the scene tree. Has a name, a parent, children, groups, and process callbacks. It has no position until you use Node2D, Node3D, or Control.Unity GameObject plus the idea of a single component, Unreal Actor component. A Godot node is both object and component.
NodePathA parsed path, written ^"UI/Score". $UI/Score is not a NodePath; it is a get_node call. % is the unique-name form of that call.A serialized object path. Unity does not have a first-class equivalent; Unreal soft object paths are the closest.
@onreadyDefers a variable's initializer until just before _ready, when children exist. @onready var label: Label = %Score. Do not combine it with @export on the same variable.Assigning in Start / BeginPlay instead of the constructor.
Output panelThe bottom-panel tab where print(), push warnings, and script errors appear. The Debugger tab is the one that pauses on breakpoints.Unity Console, Unreal Output Log.
PackedSceneA saved scene resource, usually a .tscn. instantiate() makes a node tree. change_scene_to_packed swaps the current scene.Unity Prefab asset, Unreal Blueprint class you spawn.
Parallax2DScrolls its children relative to the camera using scroll_scale. repeat_size tiles them. The Godot 3 parallax parent and layer nodes are not what this course uses.A parallax layer in any 2D engine.
Physics process_physics_process(delta). Runs on the fixed physics tick, before the physics step. Movement and collision queries belong here. _process is the variable frame tick for visuals and UI.Unity FixedUpdate versus Update, Unreal tick versus a physics substep.
Process modeNode.process_mode. PROCESS_MODE_PAUSABLE (the default) stops when get_tree().paused is true. PROCESS_MODE_ALWAYS keeps running. Pause menus need Always, or they freeze with the game.Unity timeScale ignores scripts that read unscaled time. Unreal pause with a tick group that still runs.
Project settingsProject > Project Settings. Input Map, window size, stretch, physics layers, rendering, autoloads, the main scene. Stored in project.godot.Unity Project Settings, Unreal Project Settings.
queue_freeFrees a node at the end of the frame, and frees its children. Safe during a signal. free() is immediate and easy to crash with if you are still on the call stack of that node.Unity Destroy, Unreal Destroy. Not a C++ delete you should sprinkle.
RefCountedThe default base class of a script that does not extend Node. Freed when the last reference drops. Resources are reference-counted. Nodes are not.A shared pointer / RC object. Unity objects are not reference-counted this way.
res://The project root as a path. res://player/player.tscn is portable across machines. Exported games can read it and cannot write it.A path relative to the project, like Unity's Assets/ addressed by a loader.
ResourceA serializable data object: Texture2D, PackedScene, Theme, a custom script with class_name saved as .tres. duplicate() when two owners must not share it.Unity ScriptableObject, Unreal Data Asset.
RIDAn opaque handle used by the servers (rendering, physics). You rarely construct one. RenderingServer calls on day 21 take RIDs.A GPU or physics handle, like a raw resource id behind an engine object.
RigidBody2D / 3DA body the solver moves. Set mass and forces; do not write position every frame. freeze holds it. Contact signals need contact_monitor and max_contacts_reported.Unity Rigidbody, Unreal simulating physics body.
SceneA tree of nodes saved as .tscn (text) and instanced as a unit. The running game is one scene tree. Changing scene frees the previous tree.Unity Prefab (the asset) plus Scene (the loaded world). Godot uses one idea for both.
Scene dockTop-left tree of the open scene. The + button or Ctrl+A adds a node. The chain icon instances a scene file as a child.Unity Hierarchy, Unreal World Outliner.
SceneTreeThe live tree. get_tree() returns it. Owns pause, scene changes, groups, current scene, and timers. change_scene_to_file replaces the current scene.The running world. Unity has no single object quite like it; Unreal World plus GameInstance overlap it.
SignalA list of callables on an object. signal hit(amount: int), hit.emit(5), hit.connect(_on_hit). The Node tab's Signals sub-tab connects them without code.C# event, Unity UnityEvent, Unreal delegate / event dispatcher.
StaticBody2D / 3DA collider the solver does not move. Walls and floors. constant_linear_velocity pushes things like a conveyor without animating the body.Unity static collider, Unreal static collision.
Stretch modeHow the viewport maps to the window. display/window/stretch/mode: disabled, canvas_items, or viewport. This course uses canvas_items. Aspect keep letterboxes; expand gives extra room on wide or tall screens.Unity Canvas Scaler, a render-target scale mode.
StringNameAn interned immutable string, written &"idle". Slow to create, fast to compare. Use for animation names, group names, and dictionary keys you check every frame.Unreal FName. Unity has no exact match; an interned string.
SubViewportA viewport that renders into a texture instead of the window. Pair it with SubViewportContainer for a minimap. render_target_update_mode controls when it redraws.Unity RenderTexture plus a Camera, Unreal Scene Capture.
ThemeA resource of fonts, colors, and StyleBoxes applied to Control nodes. A theme on a parent cascades. The Ship Kit keeps one at res://ui/theme/game_theme.tres.Unity UI style sheet, Unreal UMG style.
TileMapLayerOne grid of tiles from a TileSet. Collision, navigation, and occlusion can be baked into the tiles. set_cell, local_to_map, map_to_local. The older combined tile node is deprecated.Unity Tilemap, Unreal Paper2D tile map.
TileSetThe resource a TileMapLayer paints from: atlas, collision polygons, terrain peering, physics layers, custom data. Several layers can share one TileSet.Unity Tile Palette asset, a tileset texture plus metadata.
TimerA node countdown. wait_time, one_shot, autostart, signal timeout. For a one-off delay in code, await get_tree().create_timer(0.5).timeout avoids an extra node.Unity coroutine delay, Unreal timer manager.
TransformTransform2D is a 2D affine matrix. Transform3D is a Basis plus origin. Node2D and Node3D expose position, rotation, and scale on top.Unity Transform, Unreal FTransform.
TweenA short-lived interpolator from create_tween(), then tween_property. Not a node you add in the Scene dock. Killed when the node that created it dies, unless you bind it elsewhere.DOTween / Unity coroutines that lerp, Unreal timelines used as a one-shot.
Unique nameScene dock, right-click a node, Access as Unique Name. The node shows a % prefix. %ScoreLabel finds it even if you reparent it inside the same scene.A scene-local id. Unity does not have this; it is closer to a serialized direct reference that survives a move.
user://A writable per-user directory. Saves, settings, logs. On Windows it lives under the user's app data, not next to the exe. res:// is the project; user:// is the player.Unity Application.persistentDataPath, Unreal saved directory.
VariantGodot's dynamic value. An untyped variable is a Variant. It can hold any built-in, or an Object. Typed GDScript exists so you do not stay on Variant by accident.A tagged union. object in C# without static typing, or a JS value.
ViewportA rectangle that displays a 2D canvas and, optionally, a 3D world. The root of the running tree is a Window, which is a viewport. Stretch settings live on it as content_scale_mode and friends.A view plus a render target. Unity Camera output, Unreal viewport.
WorldEnvironmentHolds the Environment resource: sky, ambient light, fog, glow, tonemap. One active environment lights the 3D world. Days 10 and 12 add it next to the sun.Unity Lighting window plus post-processing volume, Unreal World Settings environment.
Y-sortCanvasItem.y_sort_enabled. Children draw in position.y order so a sprite lower on the screen draws in front. Used for top-down characters and trees. z_index is a coarser manual order.Sorting by Y in a 2D batch. Unity's Transparency Sort Axis, or a custom sort.
z_indexCanvasItem.z_index. Higher draws later (on top), within the same canvas layer. z_as_relative adds the parent's index. This is not the 3D camera's Z axis.Unity sortingOrder, Unreal UMG ZOrder.
