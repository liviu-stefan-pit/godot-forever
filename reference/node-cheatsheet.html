Node cheatsheet

The nodes this course adds, grouped the way the Create New Node dialog groups them. Each row is a one-line job, the properties and signals worth remembering, the course day that uses the node, and the class page. Inspector labels are Title Case; the names below are the script identifiers.

The old tile node is deprecated: paint with TileMapLayer. If a tutorial shows those, translate the name and keep going.

Which physics body

Every 2D body has a 3D twin with the same job. A body does nothing until it has a CollisionShape2D or CollisionShape3D child whose shape is assigned. Leave the shape node's scale at (1, 1) or (1, 1, 1) and resize the shape resource itself. Physics is not deterministic.

You needNodeYou writeYou do not
Overlap, hurtbox, pickup, area gravityArea2D / Area3DConnect body_entered / body_exited. Keep monitoring true.Expect it to block movement. It detects and influences.
Wall, floor, crate that never simulatesStaticBody2D / StaticBody3DPlace it. Optional constant_linear_velocity for a conveyor.Move it every frame and expect riders to stick. Use AnimatableBody2D for that.
Moving platformAnimatableBody2D / AnimatableBody3DAnimate or set position. Turn on sync_to_physics so riders stay on it.Apply forces. It is not a rigid body.
Player, enemy, anything you steerCharacterBody2D / CharacterBody3DSet velocity, call move_and_slide() with no arguments, read is_on_floor().Pass the velocity into move_and_slide. That was Godot 3.
Stacking, bouncing, rollingRigidBody2D / RigidBody3DSet mass, gravity_scale, maybe apply_impulse. Sleep is automatic.Write position every frame. That fights the solver. freeze if you must hold it.
A single ray or a thick rayRayCast2D / RayCast3D, or ShapeCast2D / ShapeCast3Dforce_raycast_update() when you cannot wait for the next physics frame, then is_colliding() and get_collider().Forget collision_mask. A ray uses the same mask rules as a body.

CharacterBody2D.motion_mode: MOTION_MODE_GROUNDED (default) uses up_direction (default Vector2.UP) to decide floor, wall, and ceiling. MOTION_MODE_FLOATING treats every hit as a wall, which is what a top-down game wants. floor_snap_length keeps a grounded body on downward slopes.

Which UI container

A Container ignores child anchors and lays children out from their minimum size plus size flags (size_flags_horizontal / size_flags_vertical: SIZE_FILL and SIZE_EXPAND). Use anchors on a Control that is not inside a container, or on the container itself against the viewport.

Collision layers and masks

From the physics introduction: every CollisionObject2D and CollisionObject3D has 32 layers. collision_layer is the layers this object is on. collision_mask is the layers it scans. If the other object is not on a layer included in your mask, you ignore it. Defaults are "on layer 1, scan layer 1", so a fresh project makes everything collide with everything. Name the bits in Project > Project Settings > Layer Names > 2D Physics (or 3D Physics). In the Inspector the fields are Collision > Layer and Collision > Mask.

This course uses the same names in every game:

LayerNameWho lives hereWho should scan it
1worldTiles, walls, floorsPlayer, enemies, attacks, pickups, rigid props
2playerThe player bodyEnemy attacks, pickups, triggers. Enemies scan it only if bumping the player should block them.
3enemiesEnemy bodiesPlayer attacks. The player body scans it when touch means damage.
4player_attacksPlayer hitbox areasEnemies
5enemy_attacksEnemy hitbox areasPlayer
6pickupsCoins, health, XP gemsPlayer
7triggersDoors, checkpoints, the danger linePlayer

Layer numbers in set_collision_layer_value(n, true) and set_collision_mask_value(n, true) start at 1. The bitmask for layers 1, 3, and 4 is 0b1101 (1 + 4 + 8), which the docs also write (1 << 0) | (1 << 2) | (1 << 3). An Area2D still needs monitoring (and the other object monitorable if it is also an area). A RigidBody2D only emits body_entered when contact_monitor is true and max_contacts_reported is high enough. Rays carry their own mask: collide_with_bodies and collide_with_areas are separate switches.

One shape, two questions

Put the player body on player and a child Area2D hitbox on player_attacks. The body scans world. The hitbox scans enemies. They do not share a mask, so the player does not get stuck on their own attack.
