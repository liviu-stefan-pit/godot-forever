Shortcuts

The keyboard shortcuts and mouse controls you will use every day, grouped by where you are in the editor, with a Windows column and a macOS column. Every key on this page is stated in the official docs; the few standard keys that are not are listed separately and labelled.

ReferenceWindows firstTop 25 box below
Rebind everything in Editor > Editor Settings > Shortcuts

Open Editor > Editor Settings... and switch to the Shortcuts tab. Every editor action lists its current binding there, and you can change or clear it. Buttons also show their shortcut in the tooltip when you hover for one second. Bottom-panel shortcuts live in the Bottom Panels category and the debugger "Debug with External Editor" key under Debugger.

About this list

The docs repository in this course has no standalone "default key mapping" page, so the keys below are collected from the tutorials and class reference. Defaults can change between 4.x versions: if a key does not work, check the Shortcuts tab. macOS column: an exact key means the docs state it; same means a plain key (no modifier) that is identical on macOS; Cmd+X? means the docs do not state the macOS key and it is normally the Cmd version of the Windows key, so confirm it in the Shortcuts tab.

Keep these 25 under your fingers and you will cover about 90% of daily editing. Use your browser's Ctrl+P to print this page, or just keep it on a second monitor.
