Troubleshooting

Symptom, the line you are likely to see, why it happens, and the fix. Read the Output panel first (bottom panel). The Debugger tab is the one that pauses; the Output tab is the log.

ReferenceGodot 4.x
Which error strings are quoted from the docs

Cells marked Unverified wording are the kind of line the engine prints. The docs repo does not freeze that sentence, and a patch can rephrase it. Trust the Output panel in front of you. Cells marked Docs paraphrase a behaviour the class reference or a tutorial states, not a log line.

Scripts and the parser

SymptomErrorCauseFix
The game dies the moment a node is missing or a lookup failed. Unverified wording: invalid access or invalid call on a base object of type Nil, often naming the property or method. null (shown as Nil) has no properties. A $Path that failed, a freed node, or an @export left empty. Print the value before use. Guard with if node == null: return. For objects that may have been freed, use is_instance_valid. Prefer get_node_or_null when absence is legal.
F6 errors immediately, naming a path. Unverified wording: node not found, quoting the path and the node it was relative to. The node was renamed, reparented, or never created. $ and % run from this node. _init is too early: children are not in the tree yet. Read the path in the error against the Scene dock. Put lookups in @onready or _ready. For UI, right-click the node and choose Access as Unique Name, then use %Name.
A connected method never runs. No error. None. The signal is simply not emitted, or it is connected to a different object. The usual causes: the emitter's monitoring is off, the mask does not include the other layer, a RigidBody2D has contact_monitor false, the Timer was never start()ed, the button's mouse_filter is Ignore, or you connected the signal twice to a method that returns early. A signal connected in _ready of a node that is not in the tree yet never attaches. In the debugger, select the node and confirm the connection exists (Node tab, Signals). Temporarily print on the line that should emit. Check layer, mask, and monitoring before rewriting the callback.
The script will not parse. The error points at a line that looks fine. Unverified wording: mixed tabs and spaces, or an unexpected indent. Part of the file is tabs, part is spaces. Godot cannot mix them. The official style guide says tabs. This course sets the editor to spaces, size 4, on day 1. A paste from the web often brings tabs. Editor > Editor Settings > Text Editor > Behavior > Indent > Type = Spaces, size 4. Then in the script editor use the convert-indent command from the Edit menu, or select all and re-paste the course listing. Do not mix in one file.
A callback crashes one frame after queue_free. Unverified wording: previously freed instance, or a call on a null instance that had been freed. A signal, a tween, or an await resumed and touched the node. queue_free frees at end of frame, so the same frame can still see the object; the next resume cannot. After every await, return if not is_instance_valid(self) or not is_inside_tree(). Disconnect signals before freeing if something outside holds the callable. Do not store a node in an autoload without clearing it in tree_exiting.
Disabling a shape, changing a layer, or freeing a body inside body_entered throws. Unverified wording: the line mentions flushing queries, or tells you the function is blocked during an in/out signal. Docs: the first 2D game says disabling a shape during collision processing causes an error, and set_deferred waits until it is safe. The physics server is iterating contacts. Adding, removing, or toggling shapes in that callback mutates the list being flushed. collision_shape.set_deferred("disabled", true). For a method, call_deferred("queue_free"). CONNECT_DEFERRED on the signal connection is the other legal delay.
The parser underlines a whole function with a return-type error. Unverified wording: a path does not return a value, or a void function returns one. A typed function must return on every branch. -> void may return but must not return a value. match arms are branches too. Add the missing return, or change the declared type to void if the value is unused.
Integer maths is "off by half". None. 5 / 2 is 2. Docs: if both operands of / are int, the division truncates toward zero. Write 5 / 2.0 or float(health) / float(maximum). Remainder on ints is %; on floats it is fmod. Negative remainders: posmod / fposmod.
match falls into the wrong arm. None. Docs: match is stricter than ==. 1 does not match 1.0. There is no fall-through. Match on typeof(value) or cast before matching. Put the wildcard _ last.
Assigning one typed array to another is an error even though the element type is a subclass. Unverified wording: cannot assign an array of one element type to another. Docs: an Array[Node2D] is not an Array[Node]. The element type is part of the runtime value. Typed arrays are invariant. Build a new array, or call target.assign(source), which copies elements instead of sharing the reference.
The editor says a native method cannot be overridden. Docs: warning NATIVE_METHOD_OVERRIDE, treated as an error by default. You declared get_class, queue_free, or another non-virtual engine method. Godot 4 does not reliably shadow those. Override a virtual callback (_ready, _process, _physics_process) or connect a signal. Do not silence the warning.
An exported value shows in the Inspector and then snaps back when the scene runs. Docs: warning ONREADY_WITH_EXPORT. @onready and @export on the same variable. The onready initializer runs after the exported value is applied and replaces it. Keep the export, and assign the node path in _ready only when the export was left empty. Do not put both annotations on one line.

Scenes, signals, pause

SymptomErrorCauseFix
F6 runs a scene that does not contain your edits. None. The scene was not saved. F6 runs the file on disk. An unsaved tab has a dot on its name. Ctrl+S before F6. If the script and the scene both changed, save both.
The script runs on the wrong node. $Sprite fails, or the player never moves. Often the node-not-found line above. Attach Script was used on the parent or a sibling. The Inspector title is the node that owns the script. Select the node you meant, confirm the script path in the Inspector, detach the stray one. The root of a scene is the usual owner of that scene's script.
Pausing freezes the pause menu too. None. get_tree().paused = true stops every node whose process_mode is the default PROCESS_MODE_PAUSABLE. The menu is in that set. On the pause CanvasLayer, set Process > Mode to Always (PROCESS_MODE_ALWAYS). Children inherit it unless they override.
Changing scene leaves the old music, or a timer from the previous scene still fires. None, or a freed-instance error on the next tick. change_scene_to_file frees the current scene. Autoloads survive. A tween or a one-shot signal on an autoload may still point at a dead node. Keep music on the Audio autoload. Disconnect per-scene signals in _exit_tree. Do not store scene nodes on an autoload without clearing them.
Two clicks happen for one press. None. connect in _ready runs again if you request_ready, or you connected in the editor and again in code. Connect once. if not pressed.is_connected(_on_pressed): pressed.connect(_on_pressed). Editor connections are stored in the .tscn.
await seems to skip the rest of the function. Unverified wording: the caller used the return value of a coroutine without awaiting it. Docs: a function that awaits becomes a coroutine. Reading its result without await is an error. Calling it and ignoring the result is legal and does not wait. If you need the value, var ok: bool = await confirm(). If you do not, call it and do not read the result.

Physics

SymptomErrorCauseFix
The player walks through walls, or a hitbox never lands. None. Layer and mask do not overlap, or there is no shape. Docs: a body ignores any object that is not on a layer included in its mask. Defaults are layer 1 and mask 1. This course puts walls on world (bit 1) and expects the player to scan that bit. Inspector, Collision > Layer and Mask. Name the bits in Project Settings > Layer Names > 2D Physics. Confirm a CollisionShape2D child exists and its Shape property is not empty. See the layer table.
The character falls through the floor at the peak of a slope, or hovers. None. floor_snap_length is 0, safe_margin was raised, or the floor shape was scaled in the editor. Docs: do not scale collision shapes; edit the shape resource. Scale on the shape node should stay (1, 1). Reset the shape node's scale. Raise floor_snap_length slightly for steep slopes. Keep movement in _physics_process, and apply gravity to velocity.y before move_and_slide().
A RigidBody2D never moves, or never sleeps. None. freeze is on, gravity_scale is 0, or a script writes position every frame and fights the solver. A sleeping body is resting, which is normal. Clear Freeze. Use apply_impulse or set linear_velocity once. Do not assign position from _process.
body_entered on a rigid body never fires, while an area next to it works. None. Docs: RigidBody2D.body_entered requires contact_monitor and a max_contacts_reported high enough to count the contacts. Turn Contact Monitor on and set Max Contacts Reported to at least 1, more if several bodies touch at once.
Tiles draw, and the player falls through them. None. TileMapLayer.collision_enabled is off, or the TileSet physics layer has no polygons, or that physics layer is on a different collision layer than the player's mask. Select the tile in the TileSet editor, paint the collision polygon, and match the TileSet physics layer to world. Leave collision_enabled true on the layer node.
An enemy NavigationAgent2D stands still. None, or a navigation-map warning in Output. The NavigationRegion2D was never baked, the agent is not inside the tree yet when target_position is set, or avoidance is on and nothing is connected to velocity_computed. Bake the region from the editor toolbar. Set the target after _ready. If avoidance_enabled is true, connect velocity_computed and apply safe_velocity from that signal.
A ray always misses, or always hits the caster. None. collision_mask is empty, collide_with_bodies is off, or hit_from_inside is wrong for a ray that starts inside a shape. target_position is local, not global. Point target_position in the ray's local axes. Enable Collide With Bodies or Areas to match the target. Exclude the parent by mask, not by hoping.

Drawing, UI, pixels

SymptomErrorCauseFix
UI stays in the top-left corner when the window grows, or stretches into a smear. None. Docs: stretch mode canvas_items scales the base size to the window, and there is no longer a 1:1 pixel mapping. A Control with all anchors at the top-left keeps a fixed rect. Course games set stretch mode canvas_items. Part 1 uses aspect keep. Part 2 uses expand. For a full-screen HUD, set the root Control anchors to full rect (all four anchors at the parent edges, offsets 0). Put rows in an HBoxContainer or VBoxContainer and set the flexible child's size flags to Fill and Expand. Do not mix anchors on a child of a container; the container overwrites them.
Pixel art is blurry. None. The default canvas texture filter is linear. Docs: rendering/textures/canvas_textures/default_texture_filter defaults to linear (the viewport enum value DEFAULT_CANVAS_ITEM_TEXTURE_FILTER_LINEAR). Stretch mode canvas_items also scales sprites to the window, which softens edges. The project setting page points at rendering/2d/snap/snap_2d_vertices_to_pixel and snap_2d_transforms_to_pixel for pixel-art snapping. In Project Settings, set the canvas textures default filter to Nearest, or set the sprite's Texture > Filter to Nearest (CanvasItem.TEXTURE_FILTER_NEAREST). Turn on the two snap settings above. If you need hard pixels at any window size, stretch mode viewport renders at the base size and scales the result; canvas_items will still filter when the scale is not an integer.
A button does nothing, and the click hits the game underneath or nothing at all. None. mouse_filter is Ignore on the button, or Stop on a full-screen ColorRect or Control drawn later in the tree. Later siblings draw on top and receive the click first. Button: Mouse > Filter = Stop. Decorative rects: Ignore. Pause menus belong on a higher CanvasLayer.layer than the HUD.
A PointLight2D does not light the player. None. enabled is off, energy is 0, or the light's range mask and the sprite's CanvasItem light mask do not overlap. A CanvasModulate that is pure white hides the effect because the unlit canvas is already bright. Darken CanvasModulate.color. Confirm Light2D > Enabled and Energy. Match the light mask bits.
Particles emit in the editor and not in the game, or the opposite. None. emitting is off at runtime, visibility_rect does not cover the particles so they are culled, or amount is 0. one_shot finished before you looked. Turn Emitting on when the effect should start. Enlarge Visibility Rect. For a burst, set one_shot, set emitting true, and restart by toggling it.
Parallax2D ignores the position you set in _ready. None. Docs: after the node enters the tree, position changes are overwritten when ignore_camera_scroll is false or screen_offset is modified. Drive scroll_offset, scroll_scale, and autoscroll. Set ignore_camera_scroll only when you want to move it yourself.
No sound, and the player node looks correct. None. stream is empty, the bus is muted, volume_db is a large negative number, or playing was set before the stream was assigned. 2D audio with a tiny max_distance is silent at the camera. Assign the stream, check the Audio panel bus volumes, and call play() after the stream is set. For AudioStreamPlayer2D, raise max_distance or move the listener.

Saves, imports, export

SymptomErrorCauseFix
A saved integer comes back as 10.0, and a typed int assignment fails or a dictionary key misses. Unverified wording: a type error assigning a float to an int. Docs: JSON has a single number type, and JSON.stringify writes every number as a float. The file is correct JSON. Godot parses numbers with String.to_float. On load, int(data["coins"]) for counters. Store Vector2 as a two-element array and Color as an HTML hex string. Idle-clicker magnitudes past 2^53 must be strings.
JSON.parse_string returns null. parse_string does not report the error. Use var json := JSON.new(), then json.parse(text), then json.get_error_message() and json.get_error_line(). Truncated file or a hand-edited save. Trailing commas in arrays and objects are ignored, so they are not the cause. parse_string returns null on failure. Keep the previous good save. Write to user://saves/slot.json.tmp and rename over the real file, which is what the Ship Kit save manager does. Do not print the whole file into a widget and edit it by hand.
Exporting does nothing, or the preset shows a template error. Unverified wording: missing export template, or the template version does not match the editor. Templates are installed per editor version. A project last saved in 4.3 and opened in 4.4 still needs the 4.4 templates. Editor > Manage Export Templates and download the pack that matches Help > About. Then Project > Export.
The Android build installs and then Play or the phone rejects the update. Or the export dialog will not sign. Unverified wording: a keystore password error, or an adb install failure about signatures. Docs: create the store with keytool -v -genkey -keystore mygame.keystore -alias mygame -keyalg RSA -validity 10000. The keystore password and the key password currently have to be the same. Debug exports use the editor's debug keystore. Release exports use the path, alias, and passwords on the Android preset. A second release signed with a different key cannot update the first install. For a local phone test, export a debug build. For Play, generate the keystore once, store the passwords, and point the Release keystore fields at that file. Uninstall the debug build before installing a release build if the signatures differ.
The editor says resources are missing, imports are stale, or a texture is a blank box after a git pull. Unverified wording: a failed import, or a missing .import sidecar. Docs: imported data lives in res://.godot/imported/. That folder is a cache. It should not be committed. If it is half-written or from another machine, the editor shows broken resources even though the source PNG is fine. Close the editor. Delete the .godot folder inside the project. Do not delete project.godot. Reopen the project and let it reimport. Commit .import files and the source assets; leave .godot/ out of version control.
A script change does nothing, and the class list still shows the old type. Unverified wording: class name conflict, or failed to load script. Two files declare the same class_name, or a parse error unloaded the script and the editor is still holding the previous global class. Search the project for the class name. Fix the parse error shown in Output. Project > Reload Current Project if the global class list stays stale after the script is valid.
Writing a save throws, but the path looks right. Unverified wording: cannot open the file, or the path is read-only. An exported game cannot write res://. FileAccess.open returns null on failure; the error is on FileAccess.get_open_error(). Write under user://. Check the error code instead of assuming open succeeded. Create parent folders with DirAccess.make_dir_recursive_absolute before the first save.

Editor and project recovery

SymptomErrorCauseFix
The project opens on a blank scene, or the editor layout is nonsense after a crash. Unverified wording: a recovery prompt, or a project-settings parse failure. Editor layout and the import cache live in .godot/. project.godot is the project. A crash can leave the editor metadata half-written. The scenes and scripts are still the .tscn and .gd files. If Godot offers to restore, accept it once and then save. If the editor will not open the project, move .godot aside (do not delete project.godot) and reopen. Your scenes are untouched. Commit early so a bad .tscn merge is a git checkout, not a reconstruction.
F5 runs the wrong scene. None. The main scene is whatever was saved in Project Settings > Application > Run. F6 is the open scene. F5 is the main scene. Set the main scene in the project settings, or use F6 while you are testing one scene.
The game window is black in 3D. None. No Camera3D with current set, no light, or the camera's near / far clip the whole level. A WorldEnvironment with a black ambient and no lights looks the same. Select the camera and turn Current on (the editor can preview it). Add a DirectionalLight3D. Check Near and Far.
A breakpoint never hits. None. The game was exported as a release build, or you are looking at Output instead of Debugger. assert is stripped from non-debug exports. Docs: assertions are ignored in non-debug builds, and a failed assert pauses the game when you run from the editor. Run with F5 or F6 from the editor. Open the Debugger tab. Release exports drop assert and most debugger hooks on purpose.
The remote scene tree is empty while the game runs. None. The Scene dock shows the edited scene until you switch it to Remote. That switch appears while a game launched from the editor is running. Run the game, then in the Scene dock choose Remote. You can inspect live properties. Switch back to Local before editing.
An old tutorial's code will not parse. Unverified wording: unexpected identifier, often on a line that used to be legal. The tutorial is Godot 3. The coroutine keyword, the old export keyword, instance() on a packed scene, and kinematic body types are not the Godot 4 API. This course does not use them. Use await, @export, instantiate(), and CharacterBody2D / CharacterBody3D. Translate the node, then the call. Do not install Godot 3 to follow this course.
